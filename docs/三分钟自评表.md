# 快照自评（三分钟 · 跟踪门禁）

> **产品名**：对外叫「再测此刻 / 跟踪 / 认真聊前看一眼」——**不是「心理评估」本体**。心理评估主指 [`基线问卷.md`](./基线问卷.md)（见产品方案 §0.7）。  
> **与跟踪**：本表即心理跟踪的**唯一短记录**；趋势图走本表。  
> 用途：命名当下状态、影响面、「今天想带走什么」；认真聊门禁；写入跟踪曲线。  
> 性质：**职场向自我觉察**，不是临床测评，不做诊断。  
> **主入口**：[`产品方案_v1.md`](./产品方案_v1.md) §0.7 · §0.8 · §0.5 A · §5.5  
> 姊妹：[`基线问卷.md`](./基线问卷.md)（=心理评估）· [`职场大五画像问卷.md`](./职场大五画像问卷.md) · [`体验与文案_温暖感样板.md`](./体验与文案_温暖感样板.md)  
> **疏导用法**：有则必注入，并与**最新基线、职场画像（若有）合读**（§0.8）。  
> **与基线**：完成后若尚无基线，结果区须提供「去做心理评估」（可先去聊）。  
> 版本：v1.5 · 2026-08-11

---

## 1. 使用说明

| 项 | 建议 |
|----|------|
| 时长 | 约 3 分钟 |
| 何时用 | **认真聊**门禁（建议）；主动「再测此刻」；高压节点软提示；**非每日强制** |
| 入口位置 | 认真聊选中后须在**模式切换下方/场景列表上方**；页底跟踪入口不能当作唯一入口 |
| 结果用途 | 注入当次教练上下文；写入跟踪曲线；无基线时引导续做基线 |
| 结果呈现 | 复述勾选与分数 + 对齐「想带走什么」；禁止诊断病名 |
| 是否每次跟踪都记 | **否**。轻松聊/纯浏览不记；当日已有快照可「沿用今天的」；详见产品方案 §0.7 |

开填时可有一句轻提示：没有标准答案，勾最贴近此刻的即可。  
与「轻松聊聊」关系：轻松聊可跳过本表；认真聊应以本表为默认前置（跳过策略若开放须在主行动区明示，而非藏在页底）。

完成后回跳：若带 `next=coach&scene=&mode=formal`，应直达创建会话，**不要**只回到 home。  
若用户尚无基线：结果区并列 CTA「继续完善基线」与「先去聊」。

## 2. 题目正文

### 一、你今天主要是哪种感觉？（勾选不超过 2 项）

- [ ] **累** —— 身体累、脑子累、说不出为什么累  
- [ ] **烦** —— 坐不住、容易炸、看见什么都想关掉  
- [ ] **空** —— 没什么感觉，也对什么都没什么感觉  
- [ ] **怕** —— 担心做不好、担心被否定、担心未来  
- [ ] **堵** —— 有话说不出、有火发不出、有泪流不出  
- [ ] **无所谓** —— 就这样吧，好不好都行  

字段：`feelings[]`，枚举 `tired | irritable | numb | afraid | stuck | indifferent`，最多 2 项。

---

### 二、这种感觉有多久了？

- [ ] 就这两三天  
- [ ] 一两周了  
- [ ] 一个月以上  
- [ ] 说不清，好像一直这样  

字段：`duration` = `few_days | one_two_weeks | over_month | unclear_chronic`

---

### 三、它影响了你生活的哪部分？（可多选）

- [ ] **睡眠** —— 睡不着、早醒、睡不实  
- [ ] **胃口** —— 不想吃、吃得没味、暴吃  
- [ ] **集中力** —— 盯不住屏幕、看什么都飘  
- [ ] **脾气** —— 对家人 / 同事容易不耐烦  
- [ ] **身体** —— 头疼、胸闷、胃不舒服、肩膀紧  
- [ ] **都没影响，就是心里不爽**  

字段：`impacts[]`，枚举 `sleep | appetite | focus | temper | body | mood_only`  
注：若勾选「都没影响，就是心里不爽」，可与其他项互斥，或允许并存时以前者为弱影响标记。

---

### 四、如果给现在的状态打分 ——

**0 分** = 完全没事  |  **10 分** = 难受到影响日常生活  

现在是几分？　　`____` 分  

字段：`distress_score`，整数 0–10。

---

### 五、最近有没有具体的事，让你状态明显往下走的？

写一两句就行。不想写也可以空着。  

字段：`trigger_note`，选填短文本。

---

### 六、今天走出这个门的时候，你最想带走什么？

选一个最在意的：

- [ ] **想通一件事** —— 脑子里有个结想解开  
- [ ] **找回一点力量** —— 最近被消耗得太厉害了  
- [ ] **有一个能用的小办法** —— 明天就能用上的那种  
- [ ] **只是想找个人说说话** —— 说出来就舒服了  
- [ ] **我也不知道想带走什么** —— 但我来了  

字段：`takeaway` = `clarity | strength | tiny_tool | just_talk | unsure_but_here`（单选）

## 3. 与教练会话的衔接

| 用户选择（第六题） | 教练侧默认重心 |
|--------------------|----------------|
| 想通一件事 | 澄清事实 vs 评判；帮找「那个结」 |
| 找回一点力量 | 资源与已做到的事；小步恢复感 |
| 有一个能用的小办法 | 24 小时内可执行的一个动作 / 一句话 |
| 只是想找个人说说话 | 先充分倾听与命名情绪，再轻问是否需要行动 |
| 我也不知道想带走什么 | 不急着给方案；陪着命名一、二题的感觉即可 |

当 `distress_score >= 8`，或「空 / 无所谓」持续且 `duration` 为一个月以上：教练语气放缓，并视情况提示可寻求专业支持（仍不做诊断）。  
本表**不含**完整危机筛查；若对话中出现自伤等信号，仍走产品方案中的危机转介流程。

## 4. 数据字段（逻辑模型）

```
QuickSelfCheck          # 三分钟自评
  - user_id
  - at
  - version             # v1
  - feelings[]          # 最多 2
  - duration
  - impacts[]
  - distress_score      # 0–10
  - trigger_note?
  - takeaway
  - related_coach_session_id?
```

可映射到日常跟踪：`distress_score` → 压力分（可换算或并列存）；`feelings` → 情绪标签；`trigger_note` → 事件备注。

## 5. 与基线层的关系

| | [基线问卷](./基线问卷.md) | **快照（本文）** |
|--|------------------------------------------|------------------|
| 产品名 | **心理评估**（基线） | 跟踪 / 再测此刻（非评估本体） |
| 深度 | 5–8 分钟：场景/压力源/期望/安全筛查 | ~3 分钟：感觉/影响/想带走什么 |
| 典型时机 | 首次建档、随时更新基线 | 认真聊门禁、跟踪、再测此刻 |
| 入口 | 工作台 / 我的评估 / 快照后引导「去做心理评估」 | 认真聊主行动区；「再测此刻」 |

详见产品方案 §0.7。
