# 职场大五画像问卷（简版 · 15 题）

> 用途：可选的**趣味快速入口**，参考大五人格（OCEAN）建立职场人五维画像；**有则必作为后续疏导考量**（与基线、快照合读）。  
> 性质：**职场风格参考**，非临床测评、非录用依据、非命运标签；不宣称官方 NEO/BFI 版权量表。  
> 题量：**15 题**（每维 3 题），约 3 分钟。  
> **主入口**：[`产品方案_v1.md`](./产品方案_v1.md) §0.6 · §0.8 · §5.6  
> 姊妹文档：[`基线问卷.md`](./基线问卷.md) · [`三分钟自评表.md`](./三分钟自评表.md) · [`体验与文案_温暖感样板.md`](./体验与文案_温暖感样板.md)  
> **疏导 / 诉求**：若有画像则注入，并与**最新基线、最新快照合读**（§0.8）；不得只当趣味结果页。  
> 版本：v1.4 · 2026-08-11

## 1. 使用说明

### 1.1 何时出现

- 登录后工作台：**趣味入口**「测测你的职场画像」（与「想聊聊吗」并列或轻提示，**非进门必做**）  
- 结果页 CTA：「带着画像去聊聊」→ 轻松聊 / 认真聊  
- 可重测：建议间隔 ≥ 30 天，或用户主动「更新画像」

### 1.2 与其他问卷分工

| | 职场大五画像（本文） | 三分钟自评（快照） | 心理评估基线 |
|--|----------------------|-------------------|--------------|
| 测什么 | 较稳定的风格偏好（五维） | 当下状态 | 场景/压力源/期望 |
| 趣味性 | 高（人设 + 标签） | 中 | 低 |
| 进门 | 可选吸引 | 认真聊门禁 | 自愿；**可多次更新** |

### 1.3 知情一句（开填前）

> 这是趣味职场风格速测，用来帮教练更懂你的协作与压力习惯。不是心理诊断，也不影响任何录用判断。

## 2. 五维定义（职场口径）

| 代码 | 维度 | 职场高分倾向（描述性） | 职场低分倾向（描述性） |
|------|------|------------------------|------------------------|
| O | 开放性 | 爱试新方法、跨界联想强 | 务实稳健、偏好验证过的路径 |
| C | 尽责性 | 计划清、收尾稳、靠谱感强 | 灵活机动、不太被流程绑住 |
| E | 外向性 | 场上活跃、恢复靠互动 | 深聊少量人、独处回血 |
| A | 宜人性 | 先顾关系与共识 | 直接、敢顶、边界感强 |
| N | 情绪波动性 | 压力下感受更敏锐、易内耗 | 情绪较稳、回弹快 |

计分后每维得到 **1.0–5.0** 均分，并映射为 **0–100** 展示分（见 §4）。  
**没有**「15 题加总满分 100」；是五维各自 0–100。

## 3. 题目正文（15 题 · 每维 3 题）

统一量表：

> **1** = 非常不符合 **2** = 比较不符合 **3** = 一般 **4** = 比较符合 **5** = 非常符合

| 题号 | 维度 | 方向 | 题目（职场情境） |
|------|------|------|------------------|
| Q1 | O | 正向 | 面对新业务或新技术，我常会主动去摸一摸「还有没有更好的做法」。 |
| Q2 | O | 正向 | 聊工作方案时，我喜欢把不同领域的经验扯到一起，看看有没有新组合。 |
| Q3 | O | 反向 | 只要现有流程还能用，我更想少改结构、少碰不确定的方案。 |
| Q4 | C | 正向 | 重要交付前，我会把里程碑和风险点提前排清楚，而不是临场抱佛脚。 |
| Q5 | C | 正向 | 答应别人的事，我通常会跟到底，很少不了了之。 |
| Q6 | C | 反向 | 计划经常变，我更习惯走到哪想到哪，细则以后再说。 |
| Q7 | E | 正向 | 跨部门对齐或客户会，我往往愿意先开口带动气氛、把议题推起来。 |
| Q8 | E | 正向 | 头脑风暴或团建里，和一群人一起吵方案会让我更有劲。 |
| Q9 | E | 反向 | 连续社交或开会后，我更需要独自待一会儿才能缓过来。 |
| Q10 | A | 正向 | 意见不合时，我更想先找都能接受的点，而不是先争对错。 |
| Q11 | A | 正向 | 同事卡住时，我愿意先伸手帮一把，哪怕会占一点自己的时间。 |
| Q12 | A | 反向 | 为了把事情做成，我可以比较直接地指出问题，哪怕场面一时尴尬。 |
| Q13 | N | 正向 | 被挑战或挂面后，我脑子里容易反复回放，短时间难抽离。 |
| Q14 | N | 正向 | 临近述职、谈薪、答辩或关键评审，我的紧张感会明显抬头。 |
| Q15 | N | 反向 | 压力来了，我大多能较快稳住情绪，继续把下一步做掉。 |

字段：`answers[q1..q15]`，整数 1–5。

## 4. 计分与五维数据表

### 4.1 题目分转换

- **正向题**：得分 = 作答分（1–5）  
- **反向题**（Q3, Q6, Q9, Q12, Q15）：得分 = `6 - 作答分`

### 4.2 维度均分（每维 3 题）

| 维度 | 题目 | 均分公式 |
|------|------|----------|
| O | Q1, Q2, Q3 | `(s1 + s2 + s3) / 3` |
| C | Q4, Q5, Q6 | `(s4 + s5 + s6) / 3` |
| E | Q7, Q8, Q9 | `(s7 + s8 + s9) / 3` |
| A | Q10, Q11, Q12 | `(s10 + s11 + s12) / 3` |
| N | Q13, Q14, Q15 | `(s13 + s14 + s15) / 3` |

### 4.3 展示分（0–100）

`display = round((mean - 1) / 4 * 100)`  
便于雷达图；内部仍可存原始均分。某一维均分到 5.0 时，该维展示分为 100。

### 4.4 档位（用于人设与标签）

| 档位 | 均分区间 | 展示含义（对用户） |
|------|----------|--------------------|
| 低 | 1.00–2.49 | 偏低 |
| 中 | 2.50–3.49 | 中等 |
| 高 | 3.50–5.00 | 偏高 |

### 4.5 五维数据表（逻辑模型 / 结果存储）

```
WorkplaceBigFiveProfile
  - user_id
  - completed_at
  - version                 # v1.1+
  - raw_answers             # { q1: 1..5, ... q15 }
  - scores                  # 见下表
  - persona_id              # 主人设
  - persona_title           # 展示名
  - persona_blurb           # 趣味短文案
  - tags[]                  # 附加标签
  - coach_hints[]           # 给教练的 2–3 条配合提示（可内置模板）
```

**scores 五维数据表（对用户 / 对系统）**

| 字段 | 类型 | 说明 |
|------|------|------|
| openness.mean / .display / .band | number / int / low\|mid\|high | 开放性 |
| conscientiousness.* | 同上 | 尽责性 |
| extraversion.* | 同上 | 外向性 |
| agreeableness.* | 同上 | 宜人性 |
| neuroticism.* | 同上 | 情绪波动性 |
| top_dims[] | string[2] | 均分最高的两个维度代码（并列按 O>C>E>A>N 次序打破） |
| low_dims[] | string[2] | 均分最低的两个维度代码 |

结果页最少展示：五维条/雷达 + 主定设 + 3–5 个标签 + 「带着画像去聊聊」。

## 5. 有趣人设（主定设 · 必须带刺）

**文案铁律**：禁止纯表扬鸡汤。标题抓眼、短句带刺；正文用**一段合写**同时点出锋利面与代价（能力怎么帮你、又怎么反噬），**不要**拆成「双刃 / 硬伤」两栏重复展示。标签也要能刺到行为代价，不只贴金。

权威文案以代码库 `apps/api/internal/bigfive/profile.go` 的 `personaCatalog` / `pickTags` 为准；回看旧结果时服务端应刷新为**单段 body**（若库内仍存 edge/shadow 字段，展示层合并成一段，去掉「双刃：」「硬伤：」分栏标题）。

规则：先取 **top_dims 最高维** 与 **第二高维**（若第二高与最高差 < 0.30，视为双高组合；否则用「最高维 + N 档位」微调）。  
命中多条时取**更具体的组合人设**，否则用单维主设。

### 5.1 组合人设（示例口径）

| persona_id | 人设名 | 趣味一句话（带刺） |
|------------|--------|--------------------|
| bridge_builder | 人形灭火器 | 火药味降了，账单记在你情绪账户上。 |
| quiet_architect | 隐形总控 | 坑是你填的，功劳常漂走。 |
| storm_pilot | 焦虑发动机 | 紧张焊成清单，再加班证明自己。 |
| bold_challenger | 当场拆弹手 | 敢点名，也敢把人得罪干净。 |
| curious_migrator | 履历变形金刚 | 会接新接口，也容易被疑只会讲故事。 |
| steady_anchor | 情绪绝缘体 | 最稳的人，最容易被默认永不累。 |
| empath_radar | 人形气压计 | 读空气准，过载也快。 |
| solo_craftsman | 耳机里的军师 | 方案在深水，存在感易饿死。 |
| flexible_firefighter | 救火成瘾者 | 能冲火场，也离不开火。 |
| principled_editor | 质量原教旨 | 标准硬，也常被写成难搞。 |
| … | （其余见代码 catalog） | |

### 5.2 单维主设（示例）

| persona_id | 人设名 | 短句 |
|------------|--------|------|
| open_explorer | 新坑试吃员 | 试吃盘永不买单。 |
| reliable_closer | 收尾强迫症 | 做完才安心，然后没人问累不累。 |
| social_spark | 冷场灭霸 | 救场上瘾，会后空账。 |
| harmony_keeper | 共识讨好债 | 共识成了，委屈进账。 |
| deep_feeler | 全天候警报器 | 预警准，误报也关不掉。 |

### 5.3 人设展示结构

```
title:  人设名（抓眼，可带刺）
blurb:  一句带刺短句（锋利面与代价揉在一句里即可）
body:   一段合写（80–140 字）：先写怎么好用，紧接着写代价/硬伤；禁止分栏「双刃」「硬伤」重复展示
tags:   3–6 个，含代价向标签
```

**结果页 UI**：人设区只展示 `title` + `blurb` + **一段** `body` + 标签云。  
**禁止**：双栏「双刃 / 硬伤」、或 body 内再套「双刃：… / 硬伤：…」两段标题（概念重复、读感像复读）。

合写示例口径（勿当最终文案）：

> 你会场一坐火药味就降两度，别人靠你灭火——账单却记在你情绪账户上；冲突散了你未必散得了，讨好式灭火练久了，真心话会越来越晚出口。

## 6. 附加标签（可多选叠加 · 代价向）

标签与人设并行，**3–6 个**。规则：高维标签要带行为代价，低维标签可刺刻板印象；禁止纯贴金（如只写「靠谱」「开朗」）。

实现以 `pickTags` 为准，口径示例：

| 条件 | 标签示例 |
|------|----------|
| O高 | `#新坑试吃` `#收口困难户` |
| O低 | `#路径依赖户` `#创新过敏体质` |
| C高 | `#收尾强迫` `#不喊停会死` |
| C低 | `#救火成瘾` `#无火就慌` |
| E高 | `#场上带电` `#会后空账` |
| E低 | `#深水黑箱` `#存在感易饿死` |
| A高 | `#讨好债户` `#边界漏风` |
| A低 | `#直球伤人` `#正确但孤立` |
| N高 | `#会后复盘脑` `#误报刷屏` |
| N低 | `#情绪绝缘` `#被当永动机` |
| 组合 | `#焦虑当燃料` `#灭火耗材本人` `#温吞创新风险` `#别用中庸骗自己` 等 |

文案约束：可自嘲、可刺痛；**禁止**病名化或羞辱人格（如乱扣精神疾病名）。

## 7. 教练配合提示（结果页 / 注入疏导）

注入疏导时：本卷摘要须与**最新基线、最新快照**一并合读（产品方案 §0.8），不得只塞人设。

按主定设或维度给出 2–3 条，示例：

| 方向 | 提示模板 |
|------|----------|
| N高 | 开场先帮用户区分「事实」和「脑子里的电影」，再谈行动。 |
| C高 | 对方吃「可执行下一步」；少空泛鼓励，多一起列最小步骤。 |
| E低 | 允许短回复与沉默；少用逼问式连续追问。 |
| A高 | 注意TA可能过度自责或先顾别人；帮TA练习边界句。 |
| A低 | 认可直接风格，同时练习「观点硬、关系不撕破」的说法。 |
| O高 | 用迁移与类比挖深度，避免只停留在新点子清单。 |

## 8. 结果页文案样板

**标题**：你的职场画像  
**主句**：你更像「{人设名}」——{趣味一句话}  
**描写**：一段合写正文（勿再拆双刃/硬伤两栏）  
**五维**：条形或雷达 + 低/中/高文字  
**标签**：`#…` 云或胶囊（最多 6）  
**边界**：会刺一点才有用。风格速写会随阶段变化；不是诊断，也不是能力排名。  
**CTA**：带着画像去聊聊 · 稍后再说 ·（可选）更新画像

## 9. 版权与产品边界

- 框架参考大五人格 OCEAN；题目为产品**自研职场情境题**，非 NEO-PI-R / 官方 BFI 原题照搬。
