# 职场大五画像问卷（简版 · 约 12 题）

> 用途：可选的**趣味快速入口**，参考大五人格（OCEAN）建立职场人五维画像，提升完测趣味与教练上下文。  
> 性质：**职场风格参考**，非临床测评、非录用依据、非命运标签；不宣称官方 NEO/BFI 版权量表。  
> 题量：**12 题**，约 2–3 分钟。  
> 关联：[`产品方案_v1.md`](./产品方案_v1.md) §0.6 / §5.6  
> 版本：v1 · 2026-08-11

---

## 1. 使用说明

### 1.1 何时出现

- 登录后工作台：**趣味入口**「测测你的职场画像」（与「想聊聊吗」并列或轻提示，**非进门必做**）  
- 结果页 CTA：「带着画像去聊聊」→ 轻松聊 / 认真聊  
- 可重测：建议间隔 ≥ 30 天，或用户主动「更新画像」

### 1.2 与其他问卷分工

| | 职场大五画像（本文） | 三分钟自评 | 初次心理评估 |
|--|----------------------|------------|--------------|
| 测什么 | 较稳定的风格偏好（五维） | 当下状态 | 场景/压力源/期望基线 |
| 趣味性 | 高（人设 + 标签） | 中 | 低 |
| 进门 | 可选吸引 | 认真聊门禁 | 自愿深度 |

### 1.3 知情一句（开填前）

> 这是趣味职场风格速测，用来帮教练更懂你的协作与压力习惯。不是心理诊断，也不影响任何录用判断。

## 2. 五维定义（职场口径）

| 代码 | 维度 | 职场高分倾向（描述性） | 职场低分倾向（描述性） |
|------|------|------------------------|------------------------|
| O | 开放性 | 爱试新方法、跨界联想强 | 务实稳健、偏好验证过的路径 |
| C | 尽责性 | 计划清、收尾稳、靠谱感强 | 灵活机动、不太被流程绑住 |
| E | 外向性 | 场上活跃、恢复靠互动 | 深聊少量人、独处回血 |
| A | 宜人性 | 先顾关系与共识 | 直接、敢顶、边界感强 |
| N | 情绪波动性 | 压力下感受更敏锐、易内耗 | 情绪较稳、回弹快 |

计分后每维得到 **1.0–5.0** 均分，并映射为 **0–100** 展示分（见 §4）。

## 3. 题目正文（12 题）

统一量表：

> **1** = 非常不符合 **2** = 比较不符合 **3** = 一般 **4** = 比较符合 **5** = 非常符合

| 题号 | 维度 | 方向 | 题目（职场情境） |
|------|------|------|------------------|
| Q1 | O | 正向 | 面对新业务或新技术，我常会主动去摸一摸「还有没有更好的做法」。 |
| Q2 | O | 反向 | 只要现有流程还能用，我更想少改结构、少碰不确定的方案。 |
| Q3 | C | 正向 | 重要交付前，我会把里程碑和风险点提前排清楚，而不是临场抱佛脚。 |
| Q4 | C | 正向 | 答应别人的事，我通常会跟到底，很少不了了之。 |
| Q5 | C | 反向 | 计划经常变，我更习惯走到哪想到哪，细则以后再说。 |
| Q6 | E | 正向 | 跨部门对齐或客户会，我往往愿意先开口带动气氛、把议题推起来。 |
| Q7 | E | 反向 | 连续社交或开会后，我更需要独自待一会儿才能缓过来。 |
| Q8 | A | 正向 | 意见不合时，我更想先找都能接受的点，而不是先争对错。 |
| Q9 | A | 反向 | 为了把事情做成，我可以比较直接地指出问题，哪怕场面一时尴尬。 |
| Q10 | N | 正向 | 被挑战或挂面后，我脑子里容易反复回放，短时间难抽离。 |
| Q11 | N | 正向 | 临近述职、谈薪或关键评审，我的紧张感会明显抬头。 |
| Q12 | N | 反向 | 压力来了，我大多能较快稳住情绪，继续把下一步做掉。 |

字段：`answers[q1..q12]`，整数 1–5。

## 4. 计分与五维数据表

### 4.1 题目分转换

- **正向题**：得分 = 作答分（1–5）  
- **反向题**（Q2, Q5, Q7, Q9, Q12）：得分 = `6 - 作答分`

### 4.2 维度均分

| 维度 | 题目 | 均分公式 |
|------|------|----------|
| O | Q1, Q2 | `(s1 + s2) / 2` |
| C | Q3, Q4, Q5 | `(s3 + s4 + s5) / 3` |
| E | Q6, Q7 | `(s6 + s7) / 2` |
| A | Q8, Q9 | `(s8 + s9) / 2` |
| N | Q10, Q11, Q12 | `(s10 + s11 + s12) / 3` |

### 4.3 展示分（0–100）

`display = round((mean - 1) / 4 * 100)`  
便于雷达图；内部仍可存原始均分。

### 4.4 档位（用于人设与标签）

| 档位 | 均分区间 | 展示含义（对用户） |
|------|----------|--------------------|
| 低 | 1.00–2.49 | 偏低 |
| 中 | 2.50–3.49 | 中等 |
| 高 | 3.50–5.00 | 偏高 |

### 4.5 五维数据表（逻辑模型 / 结果存储）

```
WorkplaceBigFiveProfile
  - user_id
  - completed_at
  - version                 # v1
  - raw_answers             # { q1: 1..5, ... q12 }
  - scores                  # 见下表
  - persona_id              # 主人设
  - persona_title           # 展示名
  - persona_blurb           # 趣味短文案
  - tags[]                  # 附加标签
  - coach_hints[]           # 给教练的 2–3 条配合提示（可内置模板）
```

**scores 五维数据表（对用户 / 对系统）**

| 字段 | 类型 | 说明 |
|------|------|------|
| openness.mean / .display / .band | number / int / low\|mid\|high | 开放性 |
| conscientiousness.* | 同上 | 尽责性 |
| extraversion.* | 同上 | 外向性 |
| agreeableness.* | 同上 | 宜人性 |
| neuroticism.* | 同上 | 情绪波动性 |
| top_dims[] | string[2] | 均分最高的两个维度代码（并列按 O>C>E>A>N 次序打破） |
| low_dims[] | string[2] | 均分最低的两个维度代码 |

结果页最少展示：五维条/雷达 + 主定设 + 3–5 个标签 + 「带着画像去聊聊」。

## 5. 有趣人设（主定设）

规则：先取 **top_dims 最高维** 与 **第二高维**（若第二高与最高差 < 0.30，视为双高组合；否则用「最高维 + N 档位」微调）。  
下列为人设库；命中多条时取**更具体的组合人设**，否则用单维主设。

### 5.1 组合人设（优先）

| persona_id | 条件（示意） | 人设名 | 趣味一句话 |
|------------|--------------|--------|------------|
| bridge_builder | A高 + E高 | 会议室润滑剂 | 你一进场，火药味都像被调小了一格。 |
| quiet_architect | C高 + E低 | 幕后架构师 | 话不多，但版本计划和风险清单常常是你默默补齐的。 |
| storm_pilot | N高 + C高 | 高压领航员 | 你会紧张，但紧张时常被你翻译成检查清单。 |
| bold_challenger | A低 + E高 | 当场拆弹手 | 场面冷了你敢开口，问题脏了你敢点名。 |
| curious_migrator | O高 + C中或高 | 跨界翻译官 | 你总能把旧经验讲成新岗位听得懂的语言。 |
| steady_anchor | N低 + C高 | 定海神针 | 别人还在晃，你已经在问「下一步谁做、何时完」。 |
| empath_radar | A高 + N高 | 情绪雷达站 | 你对氛围很敏感——既是超能力，也容易过载。 |
| solo_craftsman | E低 + O高 | 独处工匠 | 最好的方案，往往在你戴上耳机之后出现。 |
| flexible_firefighter | C低 + E高 | 机动救火员 | 计划改了三次你也能上场，现场感拉满。 |
| principled_editor | A低 + C高 | 严格审稿人 | 你要的是对齐标准，不是和稀泥的「大家都好」。 |

### 5.2 单维主设（无清晰组合时）

| persona_id | 条件 | 人设名 | 趣味一句话 |
|------------|------|--------|------------|
| open_explorer | top=O | 新地图测绘员 | 未知区域对你来说更像副本入口，不像障碍。 |
| reliable_closer | top=C | 收尾必胜组 | 「做完」比「做过」更让你有安全感。 |
| social_spark | top=E | 场上点火器 | 冷场三秒，你已经在找那个能接话的人。 |
| harmony_keeper | top=A | 共识收纳盒 | 你习惯先把人接住，再把事放进去。 |
| deep_feeler | top=N | 内心气象台 | 你比别人更早收到「要变天」的信号。 |

### 5.3 人设展示结构

```
title:  人设名
blurb:  趣味一句话
body:   80–120 字职场描写（可用模板拼接五维档位，勿写诊断）
fit:    「和教练怎么配合」2–3 条（见 §7）
```

## 6. 附加标签（可多选叠加）

标签与人设并行展示，**3–6 个**为宜。下列规则可叠加（按优先级截断到最多 6 个）。

### 6.1 维度档位标签

| 条件 | 标签 |
|------|------|
| O高 | `#灵感捕手` `#愿意改方案` |
| O低 | `#稳扎稳打` `#少折腾派` |
| C高 | `#靠谱收尾` `#清单体质` |
| C低 | `#即兴选手` `#反流程侠`（语气轻松，勿贬义） |
| E高 | `#场上发光` `#对齐推进器` |
| E低 | `#深水静音` `#会后充电` |
| A高 | `#关系优先` `#温和说服` |
| A低 | `#直球表达` `#标准对齐` |
| N高 | `#敏感天线` `#会后复盘脑` |
| N低 | `#情绪稳盘` `#抗压缓冲` |

### 6.2 组合彩蛋标签

| 条件 | 标签 |
|------|------|
| C高且 N高 | `#焦虑转化为行动` |
| C高且 N低 | `#稳如交付日` |
| E高且 A高 | `#空气清新剂` |
| E低且 A高 | `#小范围深同盟` |
| O高且 E低 | `#独自开地图` |
| A低且 C高 | `#质量守门员` |
| O高且 A高 | `#温和创新者` |
| 五维均在「中」 | `#弹性适应体` `#尚未显影` |

### 6.3 职场场景彩蛋（可选，基于档位推断）

| 条件 | 标签 |
|------|------|
| C高 | 求职向：`#简历好改型`（暗示结构感强，非能力保证） |
| N高 | `#述职前要热身` |
| E低 | `#一对一比群聊更在状态` |
| A低 | `#冲突场需要话术缓冲` |
| O高 | `#迁移叙事有素材` |

文案约束：标签可爱、可自嘲，**禁止**「社恐病娇」「精神有问题」等病名化或羞辱性标签。

## 7. 教练配合提示（结果页 / 注入疏导）

按主定设或维度给出 2–3 条，示例：

| 方向 | 提示模板 |
|------|----------|
| N高 | 开场先帮用户区分「事实」和「脑子里的电影」，再谈行动。 |
| C高 | 对方吃「可执行下一步」；少空泛鼓励，多一起列最小步骤。 |
| E低 | 允许短回复与沉默；少用逼问式连续追问。 |
| A高 | 注意TA可能过度自责或先顾别人；帮TA练习边界句。 |
| A低 | 认可直接风格，同时练习「观点硬、关系不撕破」的说法。 |
| O高 | 用迁移与类比挖深度，避免只停留在新点子清单。 |

## 8. 结果页文案样板

**标题**：你的职场画像  
**主句**：你更像「{人设名}」——{趣味一句话}  
**五维**：条形或雷达 + 低/中/高文字  
**标签**：`#…` 云或胶囊（最多 6）  
**边界**：这是风格速写，会随阶段变化；不是诊断，也不是能力排名。  
**CTA**：带着画像去聊聊 · 稍后再说 ·（可选）更新画像

## 9. 版权与产品边界

- 框架参考大五人格 OCEAN；题目为产品**自研职场情境题**，非 NEO-PI-R / 官方 BFI 原题照搬。  
- 对外可写：「参考大五人格的职场风格速测」；勿写「正式心理测验」「MBTI 官方」等。  
- 不做录用筛选承诺；高 N 不输出病理结论。
