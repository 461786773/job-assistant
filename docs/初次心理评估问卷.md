# 初次心理评估问卷

> 用途：用户**准备好接受个性化基线**时的心理评估，用于 AI 分析、场景推荐与跟踪对照。  
> **非进门必做**：链接登录后可先体验产品功能，再主动或在节点引导下完成（可「稍后再说」）。  
> 性质：**职场向自我评估**，不是临床心理测评，不做诊断、不开药、不替代持证咨询。  
> 关联：[`产品方案_v1.md`](./产品方案_v1.md) §0.4 / §5.4 / §5.5  
> 版本：v1.1 · 2026-08-10

---

## 1. 使用说明

### 1.1 何时填写

- **推荐**：用户主动点击「开始第一次心理评估」  
- **可引导**：进入深度个性化疏导、预约私人辅导、打开「我的评估」且尚无报告时——软提示，提供「稍后再说」  
- **不要**：把本问卷做成登录后的唯一强制全屏门禁  
- 之后可按季度或重大节点自愿重测；日常跟踪用三分钟自评等短问卷  

### 1.2 填写体验约束

| 项 | 建议 |
|----|------|
| 时长 | 5–8 分钟 |
| 题量 | 约 20–25 题（含 1 道开放题） |
| 跳题 | 按「当前主场景」分支，避免无关题刷屏 |
| 结果页 | 给「状态摘要 + 建议教练场景 + 是否建议专业求助」，**禁止**输出诊断病名 |

### 1.3 隐私与知情

开填前固定展示：

1. 答案仅本人可见（首发无组织端监控）  
2. 用于教练个性化与趋势对照，不作录用/晋升评判依据  
3. 若出现危机相关选项，将展示专业求助资源，产品不提供危机陪护  

用户需勾选「我已知晓」后方可开始。

## 2. 问卷结构

| 区块 | 目的 | 题型 |
|------|------|------|
| A. 知情与背景 | 场景与节点上下文 | 单选 / 多选 |
| B. 近期状态基线 | 压力、情绪、精力、睡眠感 | Likert 1–5 |
| C. 职场压力源 | 求职 / 晋升 / 沟通等触发点 | 多选 + 强度 |
| D. 应对与支持 | 已有调节方式与支持系统 | 多选 / Likert |
| E. 安全筛查 | 危机信号（极简） | 单选 |
| F. 期望与开放 | 希望教练优先帮什么 | 多选 + 短文本 |

## 3. 题目正文

评分题统一量表（未另说明时）：

> **1** = 几乎没有 / 很不同意 **2** = 较少 / 不太同意 **3** = 一般 **4** = 较多 / 比较同意 **5** = 非常频繁 / 非常同意

---

### A. 知情与背景

**A0.** 我已阅读并知晓：本问卷为职场自我评估，非临床诊断。  
- [ ] 已知晓，开始填写  

**A1.** 你当前最想优先处理的场景是？（单选，决定分支）  
- `job_search` 求职 / 跳槽  
- `promotion` 晋升 / 述职 / 职级沟通  
- `communication` 职场沟通 / 冲突 / 向上管理  
- `mixed` 以上都有，暂难分清  
- `other` 其他职场压力（请在 F2 说明）  

**A2.** 你目前的工作状态？（单选）  
- 在职，暂无明确离职计划  
- 在职，正在看机会 / 面试中  
- 已离职 / 空窗求职中  
- 其他  

**A3.** 近 4 周内，对你影响最大的 1–2 个事件？（多选，最多 2）  
- 投递/约面密集  
- 面试发挥失常或挂面  
- Offer / 谈薪拉扯  
- 晋升述职或职级反馈  
- 与上级预期错位  
- 跨部门冲突或被否定  
- 工作量/交付高压  
- 无明显事件，但持续紧绷  
- 其他（短填）  

**A4.** 你的工作年限大致区间？（单选，用于口径对齐，非门槛歧视）  
- 3 年以下  
- 3–5 年  
- 6–10 年  
- 10 年以上

### C. 职场压力源

**C1.** 下列哪些正在明显消耗你？（多选）  
- 简历主线说不清 / 与 JD 对不齐  
- 面试讲述表层、怕被追问穿帮  
- 谈薪不懂结构、怕被流水压价  
- 投递久了耗竭、想放弃  
- 在职偷投的焦虑或羞耻  
- 晋升述职不知怎么呈现价值  
- 怕暴露短板、被上级看轻  
- 冲突后反复内耗  
- 该争取时说不出口 / 该止损时停不下来  
- 身份迁移叙事弱（跨岗/跨赛道）  
- 其他（短填）  

**C2.** 对你当前最痛的一项，强度是？（单选，对应 C1 中自认最痛的那项）  
1 — 2 — 3 — 4 — 5  

**C3.**（分支）若 A1 = 求职  

| 题号 | 题目 | 量表 |
|------|------|------|
| C3a | 挂面或石沉大海后，我会较长时间陷入自我攻击 | 1–5 |
| C3b | 我能把「发挥问题」和「我这个人不行」分开看 | 1–5（越高越好） |

**C4.**（分支）若 A1 = 晋升  

| 题号 | 题目 | 量表 |
|------|------|------|
| C4a | 述职/晋升沟通前，我会反复 rumination、难以专注准备 | 1–5 |
| C4b | 我清楚上级/职级标准，而不只是「我觉得自己该升」 | 1–5（越高越好） |

**C5.**（分支）若 A1 = 沟通  

| 题号 | 题目 | 量表 |
|------|------|------|
| C5a | 冲突或被否定后，情绪会劫持我很久 | 1–5 |
| C5b | 我能在冷却后表达边界与诉求 | 1–5（越高越好） |

**C6.**（分支）若 A1 = mixed / other：跳过 C3–C5，仅保留 C1–C2。

### D. 应对与支持

**D1.** 压力大时，你通常会怎么做？（多选）  
- 硬扛、假装没事  
- 运动 / 睡觉 / 娱乐分心  
- 和朋友或家人说  
- 写下来 / 自己复盘  
- 找同事或导师聊  
- 专业心理咨询 /  EAP  
- 刷手机到更累  
- 饮酒或其他麻痹方式  
- 尚无稳定办法  

**D2.** 你觉得目前可依靠的支持够不够？（单选）  
- 比较够  
- 一般  
- 明显不够  
- 不确定  

**D3.** 你是否愿意在产品里做轻量状态打卡（压力/情绪）？（单选）  
- 愿意，尽量每天  
- 愿意，关键节点再打  
- 先看看，不确定  
- 暂时不想  

---

### E. 安全筛查（必答，极简）

> 说明：以下用于判断是否需要展示专业求助资源，**不是**诊断。

**E1.** 近 2 周，是否有过「活着没有意思」或伤害自己的想法？  
- 完全没有  
- 偶尔有过一闪而过的念头，但能自己拉开  
- 较频繁，或已有具体计划 / 行动（任一即触发危机资源）  

**E2.** 若选「较频繁…」：展示危机资源卡，并建议暂停深度教练、优先寻求线下专业/紧急帮助。产品内仅保留「我已知晓资源」确认，不继续高压追问细节。  

---

### F. 期望与开放

**F1.** 你希望教练优先帮你什么？（多选，最多 3）  
- 稳住情绪、减少内耗  
- 把事实和自我评判拆开  
- 挂面 / 冲突后的复盘  
- 晋升或向上沟通怎么开口  
- 谈薪前的心理准备与话术底气  
- 建立可持续的状态跟踪  
- 需要时带我去做简历/面试/谈薪训练  
- 其他  

**F2.** 用一句话描述：此刻最卡你的是什么？（选填，≤100 字）  

**F3.** 还有什么希望教练知道、但上面没问到的？（选填，≤100 字）

## 4. 计分与结果呈现（产品逻辑）

### 4.1 基线指标（内部用，可对用户展示「摘要」而非原始算法名）

| 指标 | 计算示意 | 用途 |
|------|----------|------|
| 压力基线 | B1 | 跟踪对照起点 |
| 情绪负荷 | mean(B2, B3, B4) | 教练开场语气与节奏 |
| 精力—睡眠 | B5 反向关注低分；B6 高分需提示休息 | 行动建议可行性 |
| 场景痛点强度 | C2 + 对应分支题 | 推荐场景与是否建议先教练再三关 |
| 支持充足度 | D2 | 是否强调外部支持资源 |
| 危机标记 | E1 | 覆盖层展示求助资源 |

### 4.2 结果页结构（对用户）

1. **状态一句话**：如「近两周压力偏高，求职自我否定较明显」——只用描述性语言  
2. **建议主场景**：求职 / 晋升 / 沟通（来自 A1 + C 区）  
3. **建议下一步**：先开一次教练会话 / 先打卡 3 天 / 需要时进入某关训练  
4. **边界提示**：再次说明非诊疗；若危机标记为真，置顶专业资源  

### 4.3 禁止输出

- 任何精神疾病诊断名或「你有某某症」  
- 「保证你焦虑消失 / 一定升职拿到 offer」类承诺  
- 把问卷分数直接当作录用或能力评价

## 6. 与日常打卡、三分钟自评的关系

| | 初次评估 | [三分钟自评表](./三分钟自评表.md) | 日常/跟踪短问卷 |
|--|----------|----------------------------------|----------|
| 频率 | 准备好时做一次（+ 可选重测）；**非进门必做** | 正式疏导 / 节点快评 | 正式跟踪节点 |
| 深度 | 场景、压力源、期望、安全筛查 | 感觉、时长、影响、0–10 分、想带走什么 | 同左或更简 |
| 作用 | 定基线、AI 分析、个性化推荐 | 当次教练开场对齐 | 看趋势 |
| 可跳过 | 可「稍后再说」，先体验产品 | 轻试玩可跳过 | 视会话模式 |

重测规则（建议）：距上次 ≥ 90 天，或用户主动「更新基线」；重大状态变化（如离职）可提示重测。

## 7. 文案示例（结果页）

**常规**

> 感谢你的填写。根据你的回答，近两周压力与自我否定偏高，当前更适合先从「求职场景」的教练对话开始：把挂面后的自我攻击和可改进点拆开。  
> 之后可用轻量打卡看见状态变化；需要改简历或练面试时，再进入过关训练。  
> 本评估用于自我觉察与教练个性化，不是心理诊断。

**危机标记**

> 你标出了需要被认真对待的痛苦信号。建议优先寻求专业或紧急支持（展示本地/通用求助资源列表）。  
> 产品内的职场教练不适合处理危机时刻；你确认已知晓资源后，仍可稍后使用打卡与非危机向的教练功能。
