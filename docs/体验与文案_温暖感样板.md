## 1. 问题判断（为何要改）

当前界面更像「功能工作台 / 后台面板」：顶栏入口多、卡片网格、统计数字、操作手册式文案（轻试玩、正式疏导、本周状态）。  
产品定位是**职场心理教练**，用户期望的是「有人接住我」，不是「我在填表管理任务」。

**目标气质**：安静、被接住、有人在场——会客，而不是仪表盘；也**不是大字报**。

### 1.1 工作台现状复盘（2026-08-10 截图）

已出现「文案换了、结构仍不和谐」的典型问题，观感像**局促的大字报**：

| 现象 | 为何别扭 |
|------|----------|
| 「下午好。」字号巨大、加粗顶满 | 问候被做成海报主标，压迫下方内容，不像对人说话 |
| 辅句很小、贴在大字脚下 | 层级断层：一声吼 + 一行说明书 |
| 三块场景卡通栏竖叠、卡内文字偏少 | 横向极宽、纵向扁条，像三条标语栏，局促又空 |
| 「从这里开始聊」重复三次 | 口号感强，交互像刷标语 |
| 底栏两列 + 多枚胶囊按钮 | 又回到工具条；与上方海报气质割裂 |
| 品牌行过小、问候过大 | 品牌被问候抢走，第一屏不像产品而像标语牌 |

**结论**：温暖 ≠ 把一句问候放到最大。要靠**字阶连续、行宽克制、场景作选项而非海报条**。

## 2. 设计原则

| 原则 | 要 | 不要 |
|------|----|------|
| 第一屏 | 一个主任务 + 一句陪伴话 | 多面板并列抢注意力 |
| 字阶 | 连续、可读、像对话 | 巨幅标语压一切（大字报） |
| 品牌 | 品牌名稳定可见 | 问候字号盖过品牌 |
| 文案 | 教练口吻、第二人称、短句 | 模式 jargon、同一 CTA 复读三遍 |
| 布局 | 疏导页以对话为绝对中心；工作台主区有适中行宽 | 通栏扁卡片竖叠成标语墙 |
| 卡片 | 仅交互必要处用容器；场景宜紧凑选项 | 默认处处大白卡片/阴影墙 |
| 温暖 | 冷静的松绿/雾感纸色 + 留白与节奏 | 紫渐变、奶油陶土衬线套路、霓虹发光、emoji 堆砌 |
| 训练入口 | 求职三关视觉降一级（练习室） | 与教练主场同一套仪表盘权重 |

### 2.1 建议视觉方向（供实现参考，非强制像素稿）

- **氛围名**：晨雾会客室（morning-mist studio）  
- **色感**：冷纸色底 + 平静青绿强调；避免「奶油底 + 陶土强调 + 报纸衬线」模板暖色  
- **字体**：一组有性格的 display + 清晰正文（勿用 Inter / Roboto / Arial 默认栈当品牌脸）  
- **动效**：至少 2–3 处有意节奏（如进场轻显、气泡出现、主按钮 hover），忌炫光与弹跳噪音  
- **按钮**：柔和圆角即可，避免满屏胶囊 pill 集群  

### 2.2 字阶与版心（反大字报硬约束）

面向中文工作台，建议按「对话书页」而不是「活动海报」定尺：

| 层级 | 用途 | 建议尺度（桌面） | 字重 |
|------|------|------------------|------|
| 品牌 | 求职助手 · 职场心理教练 | 约 15–17px | Regular / Medium |
| 问候 | 下午好 / 你好 | **约 28–34px**，可略用 display | Regular 或 Medium，**禁止特大加粗海报级** |
| 辅句 | 想先随便看看… | 约 15–16px，与问候间距紧（约 8–12px） | Regular，色用 muted |
| 区题 | 想聊聊吗 | 约 18–20px | Medium / Semibold |
| 场景名 | 求职这件事 | 约 16–17px | Medium |
| 场景说明 | 投递、挂面… | 约 13–14px | Regular，muted |
| 正文/元信息 | 状态、时间 | 约 13–14px | Regular |
| 链接型 CTA | 开始聊 | 约 14px，每组场景**一处即可** | Medium，用强调色 |

**版心**

- 主内容最大宽度约 **640–720px**（或居中栏），不要让三块场景卡拉满整屏通栏。  
- 问候区与主行动区之间留一段呼吸，但**不要**靠把字撑到 48px+ 制造「气势」。  
- 场景区优先：**一行一个紧凑选项**（左文案、右「聊」），或 **三列等分小选项**；避免「通栏大白条 × 3」。  

**验收（工作台）**

1. 缩略图里不应只认出两个大字「下午」——应先认出「想聊聊」区块。  
2. 问候可以温柔，但字号不得超过区题太多（建议问候 ≤ 区题的 1.6 倍）。  
3. 同一句 CTA 不在三个大卡上各贴一遍；改为选项本身可点，或右侧统一动作。

## 3. 三条主路径 · 内容与结构样板

### 3.1 登录页（链接进入）

**一屏只做一件事**：让人感到「进来是被欢迎的」，再留下名字进入。

| 元素 | 现常见问题 | 样板文案 / 结构 |
|------|------------|-----------------|
| 品牌 | 弱，或被「链接进入」盖过 | **求职助手**（主信号）+ 副题「职场心理教练」 |
| 主句 | 「链接进入」偏系统 | **你先坐一会儿。** / **这里有人听你把话说完。** |
| 辅句 | 功能说明偏说明书 | 可以先四处看看；想被更好地接住时，再做一次心理评估也不迟。 |
| 主操作 | 「进入工作台」偏工具 | **进来坐坐** / **开始今天的陪伴** |
| 字段 | 「用户名」冷 | 标签可仍为用户名；placeholder：**怎么称呼你**（或保留 default 提示在辅文） |
| 结构 | 小卡片居中像通用 SaaS | 全幅氛围底 + 品牌与主句占第一视线；表单是唯一交互容器 |

**验收**：去掉顶栏后，第一屏仍明显是「求职助手 · 教练」而不是任意后台登录框。

### 3.2 教练工作台（登录后默认落地）

**一屏主任务**：此刻要不要聊聊；其余降级为次要路径。  
**排版主任务**：像坐下来说话，**禁止**问候大字报 + 通栏标语卡。

#### 结构（少面板 · 反大字报）

```
[顶]     品牌一行（稳定字号，不要藏到看不见，也不要最大）
[问候]   中等问候 + 紧跟一句辅文（同一视觉组，不是海报+脚注）
[主行动] 「想聊聊吗」+ 模式切换（轻量）
         ★ 若选「认真聊一轮」→ 立刻在下方出现三分钟自评入口（见 §3.4）
         场景 = 紧凑可点列表/三列选项（非三条通栏大卡）
[轻提示] 初次长评估（可稍后再说）——一行邀请，非警报条
[次要]   状态一句话 · 上次聊到 · 文字链出口（少胶囊按钮墙）
[更次]   练习室入口（视觉降级）
```

不要默认四大块仪表盘；也不要「巨问候 + 三张海报卡 + 底栏按钮团」。  
**禁止**：认真聊依赖的三分钟入口只出现在页底「这几天你还好吗」区域。

#### 场景区布局样板（二选一）

**A. 列表（推荐）**

```
求职这件事          投递、挂面、不敢告诉同事时        [聊]
晋升与述职          怕讲浅、怕被看轻时                [聊]
沟通与冲突          会后还在心里吵时                  [聊]
```

整行可点；「聊」只是行尾动作，不要每张卡再印一句「从这里开始聊」。

**B. 三列小选项**  
每列：场景名 + 一行说明；点击整列开始。列宽有上限，不拉通屏。

#### 文案对照

| 位置 | 偏工具 / 偏大字报 | 样板说法 |
|------|-------------------|----------|
| 页题 | 教练工作台；或把「下午好。」做成全页最大字 | **下午好**（可不用句号撑气势）；字号见 §2.2，像招呼不是横幅 |
| 副题 | 可先体验…；或小到看不见的脚注 | 想先随便看看，或直接说一件卡住的事，都可以。与问候同组、字号接近正文 |
| 评估提示 | 推荐完成 / 更新心理评估基线 | **想让我更懂一点现在的你吗？** 大约几分钟；也可以稍后再说。已有底时用：**底还准吗？可以更新一下。** |
| CTA | 开始评估 | **好，我想被更好地理解** |
| 次 CTA | 稍后再说 | **先四处看看** |
| 疏导模式 | 轻试玩 / 正式疏导 | **先轻松聊聊** / **认真聊一轮** |
| 认真聊·自评入口 | 入口在页底状态区，难找 | 选中认真聊后，主行动区内出现：**先花三分钟看看自己**（完成后再点场景）；页底可另留跟踪入口 |
| 场景·求职 | 求职 / 跳槽 + 挂面耗竭… | **求职这件事** — 投递、挂面、不敢告诉同事时 |
| 场景·晋升 | 晋升 / 述职 | **晋升与述职** — 怕讲浅、怕被看轻时 |
| 场景·沟通 | 沟通 / 冲突 | **沟通与冲突** — 会后还在心里吵时 |
| 开聊 CTA | 每张大卡重复「从这里开始聊」 | 行/列整体可点；行尾用短词 **聊** 即可，勿三句复读 |
| 状态区 | 本周状态 / 近 7 日平均压力 | **这几天你还好吗** — 若有数据：近一周压力大约 X；没有：还没有留下记录，随时可以写一笔 |
| 短问卷 | 三分钟自评 | **花三分钟看看自己** |
| 跟踪 | 心理跟踪 | **看看我的状态轨迹** |
| 会话列表 | 最近教练会话 | **我们上次聊到** |
| 空会话 | 还没有会话。可先轻试… | 还没有开场。你准备好的时候，上面就可以开始。 |
| 三关区标题 | 求职过关训练 | **需要练功时：求职练习室**（视觉降级） |
| 新建任务 | 新建任务 | **准备一份投递练习** |
| 诉求/预约等 | 选择诉求后「确认，回此刻」 | 点选即走：求职/晋升/沟通 → **确认，开始聊**（直达会话）；勿默认回 home |
| 诉求页主按钮 | 确认，回此刻 | **开始聊** / 找工作若进练习室则用 **去练习室**（与真实跳转一致） |

#### 交互语气

- 评估、预约、三关均为**邀请**，不是任务清单打勾。  
- 未做长评测时，不出现「未完成」赤字感，用「还没做，也可以先聊」。  
- 底栏文字链可保留「我想清楚要什么」；**确认诉求后的落地必须是沟通/服务页，不是 home 中转。**  
- 页底「花三分钟看看自己」= 日常跟踪；与认真聊门禁入口是两处职责，认真聊必须以主行动区入口为准。

### 3.4 路径顺序硬规则（给前端）

完整规则见产品方案 [`产品方案_v1.md`](./产品方案_v1.md) **§0.5**。此处只强调验收：

1. **轻松聊聊** → 点场景 → 进 `/coach/:id`，无短问卷门禁。  
2. **认真聊一轮** → 主行动区出现三分钟入口 → 填完（query 带回 scene/mode）→ 再进会话；用户无需滚到页底。  
3. **诉求确认**（`/onboarding/need`）保存成功后：按诉求 `replace` 到会话或练习室，**禁止** `replace('/home')` 作为默认。推荐结合：**职场画像（若有）** + **心理评估包**（基线·最新 + 快照·最新）；见产品方案 §0.7 / §0.5-B。工作台须有「心理评估」入口，基线不可失踪。  
4. CTA 文案与跳转一致：说「开始聊」就必须进聊，不能说回此刻却只回首页。  
5. **我的评估**（`/assessments`）须分三块呈现：**基线结果**、**跟踪快照**、**职场画像**（产品方案 §4.1）；禁止混成一条时间线。

#### 工作台反例 → 正例（给前端对照截图）

| 反例（当前观感） | 正例 |
|------------------|------|
| 「下午好。」≈ 海报主标 | 「下午好」中等字号，与辅句同一组 |
| 三张通栏白卡 + 重复 CTA | 窄版心内的紧凑列表/三列选项 |
| 底栏多枚 pill | 一句话状态 + 少量文字链 |
| 品牌细若游丝 | 品牌稳定在顶，问候不要盖过它 |

### 3.3 疏导会话页

**一屏主任务**：把对话当作情绪主场；侧栏是「聊完能带走的」，不是工具导航墙。

#### 结构

```
[轻顶栏] 场景名（人话）+ 进行中/已结束 · 回工作台
[危机时] 转介文案置顶（清晰、不恐吓堆砌）
[主区]   对话流（绝对视觉中心）
[输入]   宽、静、占位像教练在问
[侧栏/底] 今天可以带走的 · 下一句可以这样说 · 少数出口链接
```

#### 文案对照

| 位置 | 偏工具的说法 | 样板说法 |
|------|--------------|----------|
| 角色名 | 教练 / 我 | **教练** / **我**（可保留）；气泡气质偏信笺而非聊天气泡皮肤 |
| 占位符 | 说说发生了什么… | **此刻最卡住的，是一件事，还是一种感觉？** |
| 发送 | 发送 / 思考中… | **告诉教练** / **我在听…** |
| 结束 | 结束本轮 | **先说到这里** |
| 结束后 | 本轮已结束。可回到工作台… | 这轮先停在这里。若还想练表达或投递，可以从下面慢慢选；也可以就这样休息。 |
| 侧栏标题 | 行动卡 | **今天可以带走的** |
| 侧栏空态 | 对话推进后会出现 24h… | 我们再往下聊几句，会一起找出一件今天就能做的小事。 |
| 话术标题 | 下一句怎么说 | **下一句，可以这样开口** |
| 出口区 | 需要过关时 | **若你想换种准备方式** |
| 链接 | 过关任务列表 / 记一笔打卡 | **去练习室看看** / **留下今天的状态** |
| 预约 | 预约私人辅导 | **想见真人时，约一次** |
| 返回 | 返回教练工作台 | **先回到安静的一页** |

#### 体验细则

- 轻试玩进入：不强调「模式名」，开场一句即可说明「这是轻松聊聊」。  
- 正式疏导：若需短问卷，门禁文案用邀请：「先用三分钟看看自己，再开始，我会更接得住你。」  
- 少暴露 status=done、relatedTaskId 等系统感字段于主视线。

## 5. 实现边界（给前端 agent）

1. **只改体验与文案层**：上述三页的布局权重、用词、视觉层级；不在本文范围改后端逻辑。  
2. **产品规则不变**：基线仍非进门必做、**可多次更新**（取最新）；快照=跟踪记录；危机转介逻辑保留。  
3. **可分 PR**：先三页样板 → 再复用词表到评估/预约/跟踪页。  
4. **验收口诀**：用户会觉得「被接住了」，而不是「又进了一个后台」。
