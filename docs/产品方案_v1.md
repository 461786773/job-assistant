# 求职助手 · 产品方案 v1

> 定位：**职场心理教练**——陪伴处于生涯高压期的人，在求职、入职适应、晋升、沟通等节点稳住状态、理清选择、练好表达  
> 教练怎么帮：用**觉察与跟踪**稳住心理，用**场景辅导**理清情绪与下一步，用**过关工具**（人事 → 业务/面试 → 谈薪）把「下一句怎么说」练到可执行  
> 首发三类人群（并列 P0）：**应届大学生**、**刚入职场的小白**、**30 多岁压力山大的中年打工人**  
> 明确不做：**临床心理诊疗 / 危机干预替代品**；不是又一个泛 AI 改简历或刷题平台

## 0. 核心策略（专项调整）

### 0.1 策略一句话

产品首先是**职场心理教练**，不是「招聘三关工具箱再挂个心理彩蛋」。用户来找的是：有人帮我在关键节点稳住、想清、说得出；简历/面试/谈薪是教练场景下的**训练与过关手段**。

### 0.2 教练模型（主从关系）

| 层 | 角色 | 解决什么 | 典型产出 |
|----|------|----------|----------|
| **教练主线** | 职场心理教练 | 求职 / 入职适应 / 晋升 / 沟通中的压力、自我怀疑、冲突耗竭；帮用户拆开事实与评判，选定下一步 | 辅导对话、行动卡、「下一句怎么说」 |
| **状态层** | 心理健康跟踪 | 用**快照**当唯一记录形态，连成可回看曲线，并挂到关键事件 / 教练会话 | 快照点、趋势、周复盘摘要 |
| **过关工具层** | 三关训练 | 简历 / 面试 / 谈薪「过不过、差在哪、怎么改/怎么答」 | 报告、模拟记录、谈薪对照与话术 |

关系：**教练主线统领** → 跟踪提供上下文 → 三关工具在需要时被教练调用或由用户主动进入，而不是反过来用工具定义产品。

### 0.3 原则与边界

- **先体验、后评测**：链接进入后可先逛功能、试分支服务；**心理评估（基线）不是进门必做**，用户确认需要或进入深度个性化疏导时再做。  
- **心理评估 = 以基线为主**：对外「心理评估」主要指 [`基线问卷.md`](./基线问卷.md)（场景/压力源/期望 + AI 报告）。快照是**跟踪与认真聊门禁**，不抢「心理评估」主名；二者仍可衔接（快照后可续做基线）。入口见 §0.7。  
- **快照 = 心理跟踪的记录方式**：不另做一套「打卡问卷」；跟踪曲线就是快照时间线的可视化（节点记录，非每日强制）。  
- **疏导三源合读**：后续 AI 疏导 / 教练会话须把 **职场画像（若有）+ 基线/心理评估（若有·最新）+ 快照（若有·最新）** 一并纳入上下文考量；缺哪项跳过哪项，**禁止只读其中一项当全貌**。见 §0.8。  
- **教练身份优先**：默认叙事是「能先感受产品有什么 → 需要时再评测与诉求深挖 → 疏导/预约 → 按需分支」，不是「先锁死做完长问卷」。  
- **职场向、非诊疗**：AI 评估与疏导支持觉察、表达整理、压力缓冲与行动建议；**不诊断、不开药**。真人私人辅导预约是**转介/预约通道**，不替代医疗机构。  
- **高风险兜底**：出现自伤/伤人等危机信号时，明确提示寻求专业/紧急帮助，产品不继续「陪聊式处理危机」。  
- **绑在真实节点上**：辅导与跟踪挂在求职、晋升、沟通等具体诉求上，避免泛泛心灵鸡汤。  
- **隐私优先**：心理健康数据默认仅本人可见；存储与导出需单独说明。  

### 0.4 主故事线（用户使用路径）

这是产品的**主故事线**；求职三关、晋升/沟通服务都是故事线中的分支。  
**体验原则：可逛可试，心理评估（基线）可延后；基线入口必须可见（§0.7）。**

```
1. 链接登录
       ↓
2. 进入工作台 / 功能导览（可跳过评测）
       可先体验：职场大五画像速测（趣味）、AI 疏导轻试、求职三关、晋升/沟通、预约等
       ↓
2b.（可选）职场大五画像：约 15 题 → 五维数据 + 有趣人设 + 附加标签
       ↓
3. 心理评估 = 基线问卷（可选时机，见 §0.7）
       · 主：基线（约 5–8 分钟）→ 场景·压力源·期望 + AI 分析报告
       · 旁路：快照（约 3 分钟）属跟踪/认真聊门禁，完成后可引导「去做/更新心理评估（基线）」
       基线入口必须可见（工作台 / 我的评估）；禁止基线失踪
       ↓
4. 询问 / 确认具体诉求（求职 / 晋升 / 沟通 / 先疏导 / 暂不确定）
       推荐路径须结合已有上下文（缺哪项就跳过哪项，不挡确认）：
       · 职场大五画像（若有）
       · 心理评估 / 基线（若有·最新）
       · 快照（若有·最新）——跟踪态，非「心理评估」本体
       皆无 → 按用户自选诉求进入，并提示「补画像/心理评估后推荐更准」
       ↓
5. 用户可随时回看「我的评估」——页面固定三块：**基线结果**、**跟踪快照**、**职场画像**（缺则空态 + CTA；见 §4.1）
       ↓
6. AI 心理疏导（教练对话）+ 支持预约私人心理辅导
       **开场上下文（有则必读、合读）**：职场画像 + 基线·最新 + 快照·最新
       ↓
7a. 诉求=找工作 → 子流程：人事 → 业务 → 谈薪
7b. 诉求=晋升 / 沟通 → 对应场景服务
       ↓
8. 持续跟踪：**快照即跟踪记录**（写入同一曲线；与是否已有基线解耦；非每日强制）
```

| 步骤 | 用户做什么 | 系统做什么 |
|------|------------|------------|
| 1 链接登录 | 打开邀请/访问链接进入应用 | 鉴权建会话 |
| 2 先体验 | 浏览工作台、试用各功能入口 | **不拦截**基线；可推趣味「职场画像」与软提示心理评估（基线） |
| 2b 职场画像 | 可选完成约 15 题大五简版 | 产出五维表 + 人设 + 标签；可注入后续疏导 |
| 3 心理评估 | 做/更新**基线问卷**（主） | 出 AI 报告；入口见 §0.7；快照另属跟踪 |
| 4 明确诉求 | 确认或补充具体诉求 | **结合**画像（若有）+ 基线·最新（若有）+ 快照·最新（若有）；皆无则自选；**确认后直达，不强制回 home** |
| 5 回看结果 | 打开「我的评估」 | **三块齐备**：①基线结果 ②跟踪快照 ③职场画像；缺哪块展示空态 CTA（§4.1） |
| 6 疏导与预约 | AI 对话疏导；可选约私人辅导 | **合读**画像 + 基线·最新 + 快照·最新（§0.8） |
| 7 求职 / 晋升沟通 | 按需进入分支 | 三关或场景服务（**不依赖**必须先做完基线） |
| 8 跟踪 | 认真聊 / 主动再测 / 关键节点留下快照 | **快照即跟踪点**；入口贴认真聊，禁止只藏页底 |

**问卷分工**

| | 职场大五画像 | **心理评估（基线）** | 快照自评 |
|--|--------------|----------------------|----------|
| 测什么 | 较稳定风格（OCEAN） | 场景/压力源/期望/安全筛查 | 当下感觉与想带走什么 |
| 题量 | ~15 题 | ~5–8 分钟（[`基线问卷.md`](./基线问卷.md)） | ~3 分钟（[`三分钟自评表.md`](./三分钟自评表.md)） |
| 产品名 | 职场画像 | **心理评估**（主） | 跟踪 / 「再测此刻」/ 认真聊门禁 |
| 进门 | 可选趣味，非必做 | 自愿深度，**须有显式入口**，非进门必做 | 认真聊主行动区建议做 |
| 产出 | 五维表 + 人设 + 标签 | AI 分析报告 | 教练开场对齐 + 曲线点 |
| 疏导 | 有则合读（§0.8） | 有则合读（§0.8） | 有则合读（§0.8） |

体验细则另见 [`体验与文案_温暖感样板.md`](./体验与文案_温暖感样板.md)。

### 0.7 心理评估（主=基线）与快照（跟踪）

#### 命名拍板

| 对外说法 | 指什么 | 文档 |
|----------|--------|------|
| **心理评估** | **主要是基线问卷**（可多次更新）+ AI 报告 | [`基线问卷.md`](./基线问卷.md) |
| **再测此刻 / 跟踪** | 快照自评；认真聊门禁与曲线点 | [`三分钟自评表.md`](./三分钟自评表.md) |
| **职场画像** | 大五趣味风格（独立入口） | [`职场大五画像问卷.md`](./职场大五画像问卷.md) |

**不要**再把快照也叫成「心理评估」本体，以免用户以为三分钟短测就是评估做完了、基线入口反而失踪。

#### 为什么还要快照？

| 若只有基线（5–8 分钟） | 若只有快照（3 分钟） |
|------------------------|----------------------|
| 每次认真聊都填长卷 → 劝退 | 没有场景/压力源/期望 → 算不上完整「心理评估」 |
| 进门强拦长卷 → 违背「先体验」 | 用户想建档时缺少 AI 报告与基线 |

快照服务**跟踪与当次开聊**；基线才是**心理评估**的主体。

#### 入口（心理评估=基线，必须可见）

| 位置 | 行为 |
|------|------|
| **工作台「心理评估」** | 无基线 →「去做心理评估」进基线卷；有基线 →「更新心理评估 / 更新基线」；**旁路**链「再测此刻」（快照），文案勿写成评估本体 |
| **我的评估** | 固定三块见 §4.1：基线结果 / 跟踪快照 / 职场画像；主 CTA 与空态分块对应 |
| **认真聊 → 快照完成后** | 若尚无基线：结果区主推「去做心理评估（基线）」；有基线则去聊，可链「更新评估」 |
| **预约私人辅导** | 无基线则推荐做心理评估；有基线可软提示「底是否还准」 |
| **诉求确认 / 深度疏导** | 无基线时软提示「做心理评估后推荐更准」 |

**反例**：工作台只有「花三分钟看看自己」、用户以为心理评估做完了；或做过基线后入口消失。  
**正例**：「心理评估」始终指向基线；快照明确是「看看此刻 / 跟踪」。

#### 推荐衔接（非必须同一次做完）

```
认真聊 → 快照（跟踪门禁）
        ↓
尚无基线？ ──是──→ CTA「去做心理评估」→ 基线卷 → AI 报告
        │
        └─否──→ 写入曲线 / 三源合读开聊

或：工作台直接点「心理评估」→ 基线卷（可不经快照）
```

近几日已有快照再去做基线：可引用快照摘要，减少割裂感。

#### 快照与心理跟踪

**拍板：快照就是心理跟踪的记录单元**（≠ 心理评估本体）。不另做打卡问卷。

| 用户感知 | 系统实际 |
|----------|----------|
| 「再测此刻」/ 认真聊前填一下 | 提交一条快照 |
| 「这几天还好吗」趋势图 | 快照时间线可视化 |
| 「去做心理评估」 | 进入**基线问卷** |

页底跟踪入口若保留，必须进**同一套快照题面**，禁止第三套表单。

#### 快照要不要「每次跟踪都记」？

**不要做成每日强制打卡。** 写入曲线的规则是「节点记录」，不是「每次进产品都填」。

| 场景 | 要不要新记一条快照 |
|------|-------------------|
| **认真聊**（正式疏导） | **建议记**；若**当日已有**可「沿用今天的」 |
| **轻松聊** | **不强制** |
| 用户主动「再测此刻」 | **记**（自愿） |
| 高压关键节点软提示 | **建议记**，可稍后 |
| 只逛工作台 / 练三关 / 看报告 | **不记** |
| 同一会话里反复进出 | **不重复记** |

### 0.8 疏导上下文：三源合读（拍板）

后续每一次 AI 疏导 / 教练会话（含轻松聊与认真聊），服务端组装开场上下文时须按下列规则 **合读**，作为交流的持续考量——不是可有可无的彩蛋。

| 源 | 文档 | 取用 | 提供什么 |
|----|------|------|----------|
| **职场画像** | [`职场大五画像问卷.md`](./职场大五画像问卷.md) | 若有 → 最新一份（人设、**一段合写描写**、标签、五维摘要、coach_hints） | 较稳定的协作与压力风格 |
| **基线 / 心理评估** | [`基线问卷.md`](./基线问卷.md) | 若有 → **最新一次**（含 AI 分析摘要 / summary_for_coach） | 主场景、压力源、期望、安全策略（**评估主体**） |
| **快照** | [`三分钟自评表.md`](./三分钟自评表.md) | 若有 → **最新一次**（认真聊当次优先用本会话关联快照） | 此刻感觉、影响面、想带走什么（**跟踪态**） |

**规则**

1. **有则必注入**：三者各自独立「若有」；缺一项不挡开会话，但不得假装用户没填过。  
2. **合读不单读**：禁止只注入快照、或只注入画像、或只注入基线而忽略其余已有源。  
3. **同类型取最新**：基线 / 快照 / 画像均以最新完成为准；历史可在「我的评估」回看，默认不整包塞进 prompt。  
4. **诉求确认（步骤 4）与疏导（步骤 6）同一套三源**：推荐路径与开聊上下文口径一致。  
5. **边界**：风格与状态参考，**禁止**诊断病名，**禁止**当作录用/晋升判断。

**反例**：认真聊只带三分钟自评、丢掉已有基线与画像。  
**正例**：system / 开场摘要里同时出现「人设风格」「基线场景与期望」「此刻快照」，教练回复据此调语气、节奏与下一步。

### 0.6 职场大五画像（趣味快速入口）

| 项 | 决策 |
|----|------|
| 框架 | **参考大五人格 OCEAN**；自研职场情境题，非官方量表原题照搬 |
| 题量 | **约 15 题**（2–3 分钟） |
| 目的 | 建立用户风格画像、提高趣味与完测动机；为疏导提供轻量上下文 |
| 产出 | ① 五维数据表（均分/展示分/档位）② **带刺主人设**（一段合写：锋利面与代价揉在一起，禁止双栏）③ 代价向标签（3–6 个） |
| 路径 | 工作台可选入口；结果页「带着画像去聊聊」；**不挡**轻松聊/认真聊主路径；**有则必注入疏导**（§0.8） |
| 边界 | 非临床、非录用、非 MBTI 官方；禁止病理化标签 |

**实现必读**：[`职场大五画像问卷.md`](./职场大五画像问卷.md)（题目、反向题、计分、人设一段合写、标签、教练注入摘要）。

### 0.5 关键路径顺序（易错点，必须按此实现）

#### A. 工作台疏导：轻松聊 vs 认真聊

```
登录 → 工作台「想聊聊吗」
        ├─ 先轻松聊聊 → 点场景 → 直接进教练会话（可不填短问卷）
        └─ 认真聊一轮
                → 【就地】展示三分钟自评入口（紧挨模式切换/场景区上方，禁止只放在页底）
                → 完成自评（或明确跳过策略若产品允许）后
                → 点场景 → 进教练会话（带自评上下文）
```

| 规则 | 说明 |
|------|------|
| 入口位置 | 「认真聊一轮」选中后，三分钟自评入口出现在**主行动区内**（模式切换正下方或场景列表正上方），用户不必滚到「这几天你还好吗」才找到 |

| 页底自评入口 | 可保留作日常跟踪，但**不能**当作认真聊的唯一入口 |

## 1. 问题与目标

### 1.1 真实痛点（来自首要用户典型经历）

| 关卡 / 场景 | 痛点 | 失败/卡点形态 |
|------|------|----------------|
| 应届求职 | 海投无反馈、项目/实习讲不深、期望与现实落差 | 焦虑失眠、临时弃考/弃面、自我否定「是不是不行」 |
| 小白适应 | 不敢问、不会拒、反馈刺耳、不知规则 | 闷头加班、会后内耗、萌生离职却更慌 |
| 30+ 压力 | 跳槽年龄焦虑、晋升窗口、家庭与工作拉扯、倦怠 | 状态崩导致发挥失常；谈崩或拖着耗竭 |
| 人事/简历 | 主线不清、与 JD 不对齐；经历厚薄不同阶段说法不同 | 有机会约不上；或投得猛却石沉大海 |
| 面试/业务 | 表达表层、压力题慌、不知如何呈现个人贡献 | 一面过二面挂；或终面崩盘 |
| 谈薪 | 不懂结构、不敢开口、被压价 | 总包预期错位；应届「随便开」事后后悔 |
| 沟通 | 冲突、向上、被否定后情绪劫持 | 该争取没争取、该止损没止损 |

### 1.2 产品目标

- **不是**泛 AI 改简历 / 泛陪聊，也**不是**通用心理健康 App 或临床咨询替代  
- **而是**一个**职场心理教练**：在求职、晋升、沟通等节点上，帮用户稳住状态、理清选择、练好表达  
- 三关（人事 / 业务 / 谈薪）是教练场景下的**过关训练工具**，服务于「这个节点我怎么过」，而不是产品的唯一身份  

### 1.3 成功标准（MVP）

首要用户按主故事线走通后，能带走：

1. **链接登录后可先体验**功能（不被基线评估拦住）  
2. 准备好时完成**心理评估（基线）** → AI 分析（可延后）；快照按认真聊/跟踪节点另记  
3. **诉求选择**（结合职场画像若有 + 基线·最新若有 + 快照·最新若有；皆无也可自选进入）  
4. 可回看的**评估结果页**（未评估时有清晰 CTA）  
5. 至少一次 **AI 心理疏导**；并看到**私人心理辅导预约**入口  
6. 跟踪短问卷可写入状态变化  

若诉求为找工作 / 晋升 / 沟通，分支服务可在**未完成基线评估**时试用。

## 2. 目标用户（必须说清：服务谁、不服务谁）

### 2.1 一句话 ICP（理想客户）

**处在生涯关口、心里绷着弦的人**——要找第一份工作的应届生、刚进社会的职场小白、或 30 多岁扛着压力的打工人——需要有人帮他们稳住状态、理清选择、把下一句话说清楚。

产品身份是**职场心理教练**（非临床诊疗）；三类人群**并列首发**，用同一套主故事线，按阶段切换场景话术与训练深度。

### 2.2 三类首要用户（P0 · 并列）

| 人群 | 大致阶段 | 典型卡住点 | 产品优先提供 |
|------|----------|------------|--------------|
| **应届大学生** | 毕业季前后 / 找第一份工作 | 期望落差、海投耗竭、面试紧张、不知如何讲项目与实习 | 求职心理疏导、校招/社招面试表达、简历主线（实习/课程项目）、谈薪起步认知 |
| **刚入职场的小白** | 入职约 0–3 年 | 适应规则、怕问傻、反馈焦虑、加班与边界、第一次绩效 | 沟通/向上、入职适应疏导、轻度求职或内部机会叙述、状态跟踪 |
| **30 多岁压力山大的中年打工人** | 约 30–39、有一定履历 | 跳槽/晋升焦虑、家庭与工作拉扯、倦怠、谈薪与被替代感 | 求职·晋升·沟通疏导、三关过关训练、谈薪结构、持续心理跟踪 |

**共性动机**：不是「再找一个改简历网站 / 心灵鸡汤」，而是「有个教练陪我过这个节点——状态别崩、话能说清」。

**典型场景锚点（各举一例）**

> **应届**：笔试过了，终面前一晚睡不着，怕被问「你最大的缺点」；想有人陪练两轮，并把「我行不行」和「我还缺哪块准备」拆开。  
> **小白**：入职第三个月，会上没敢反驳，会后一直内耗；想练一句向上反馈，而不是再默默加班证明自己。  
> **30+**：一面还行二面挂了，开始怀疑年龄与方向；既要改简历主线，又要把「自我否定」从复盘里剥出去，晚上还要盯孩子作业。

### 2.3 为什么是这三类（而不是「所有人」）

1. **节点清晰**：求职破冰、入职适应、三十岁关口，都是高频、可感知的高压带，适合教练式陪伴。  
2. **能力问题与心理问题缠在一起**：只改简历/只倾诉都不够，需要「疏导 + 可选过关训练」。  
3. **同一产品骨架可复用**：主故事线（画像 → 疏导 → 诉求分支 → 跟踪）不变；变的是场景题库与三关深度（应届偏表达与选择，小白偏沟通适应，30+ 偏迁移/晋升/谈薪）。  
4. **趣味画像（大五）适合破冰**：三类人都能用快速人设降低进入门槛。

原「仅 3–10 年 ToB/安全/合规」收为 **P1 垂类增强**（题库与案例包），不再当作唯一 ICP。

### 2.4 设置页 / 对外说明（标准文案）

供「设置与说明」页直接使用（实现须与此一致）：

**产品定位**

> 默认身份是**职场心理教练**：在求职、入职适应、晋升、沟通等节点，帮你稳住状态、理清选择、练好表达。人事 / 面试 / 谈薪是可调用的过关训练工具。  
> 主要服务：**应届大学生**、**刚入职场的小白**、**30 多岁压力较大的职场人**。不做临床诊断，也不替代持证心理咨询。

**隐私**（可保持现有三条，略作通用化）

> 任务与教练会话按账号隔离，仅本人可见。心理健康相关记录默认仅本人可见；首发无组织端监控。数据用于教练个性化与趋势对照，不作录用/晋升评判依据。

### 2.5 明确不服务（Out of scope）

| 非目标用户 | 原因 |
|------------|------|
| 需要临床心理治疗 / 精神疾病诊疗者 | 职场支持边界；须引导专业服务 |
| 把产品当 24h 危机热线者 | 仅识别与转介，不做危机陪护 |
| 以刷题/算法竞赛为主的纯技术应聘者（只要题库） | 过关逻辑不同；本产品不做题库平台 |
| 想「一键海投 / 编造经历骗过筛选」者 | 与可验证、不编造原则冲突 |
| 未成年人（未满 18 岁）独立使用 | 合规与监护责任；首发不做 |

说明：**应届生与职场小白已纳入 P0**，不再列在不服务表。

### 2.6 次要用户（P1，可服务）

- 有 ToB / 安全 / 合规等垂类背景的资深求职或晋升者（复用原行业题库作增强包）  
- 转行但已有可讲项目的人（按就近人群话术，不承诺「零基础包就业」）  
- 售前 / 方案等相邻角色，需要沟通与叙事教练者  

### 2.7 用户分层与产品对应

| 层级 | 是谁 | 产品必须提供的 |
|------|------|----------------|
| P0 | 应届大学生 | 求职焦虑疏导、面试表达、简历主线（实习/项目）、起步谈薪认知、画像与跟踪 |
| P0 | 刚入职场小白（约 0–3 年） | 适应与沟通疏导、边界与反馈、轻度求职/内部机会、跟踪 |
| P0 | 30 多岁压力大的打工人 | 求职/晋升/沟通疏导、三关训练、谈薪、倦怠与选择澄清、跟踪 |
| P1 | 垂类资深（如 ToB/安全/合规） | 在 P0 骨架上叠加行业题库与案例深度 |
| 不做 | 临床诊疗需求；未成年人主路径 | 见 2.5 |

### 2.8 核心场景

主故事线见 **§0.4**。以下为分支展开。

**分支：求职过关（步骤 6）**

```
上传简历 + 粘贴 JD
    → 人事评分与改写建议
    → 业务模拟 + 反表层化诊断
    → 谈薪结构对照与话术
    → 关键节点回到疏导 / 问卷跟踪
```

**分支：晋升 / 沟通（步骤 7）**

```
基于评测 + 诉求进入场景服务
    → 教练疏导（述职压力 / 冲突 / 向上表达等）
    → 可执行动作与「下一句怎么说」
    → （后续可增强）述职稿、沟通演练等专用能力
    → 问卷跟踪回写状态
```

次要场景（后期）：多 JD 主线对比、挂面复盘、STAR 案例库、私人辅导预约履约回访。

### 4.1 我的评估页（固定三块）

路由建议：`/assessments`。这是用户回看「我被了解了多少」的总页，**必须同时包含以下三块**（顺序建议如下；实现可折叠，但不得省略整块）。

| 块序 | 标题（建议） | 内容 | 空态 CTA |
|------|--------------|------|----------|
| ① | **基线结果**（心理评估） | 最新基线摘要 / AI 报告要点；可进报告详情；链「更新心理评估」；可选展开历次基线 | 「去做心理评估」→ 基线问卷 |
| ② | **跟踪快照** | 近几条快照列表 + 近 7/30 日趋势入口（或摘要）；链「再测此刻」 | 「花三分钟看看自己」→ 快照 |
| ③ | **职场画像** | 最新人设名、短句、**一段合写描写**、标签云；链详情 /「更新画像」（勿再拆双刃/硬伤两栏） | 「测一下职场画像」→ 大五问卷 |

**规则**

1. **三块常驻**：有数据就展示结果，没数据就展示该块空态——禁止整页只有时间线、或把画像挤出页外。  
2. **命名分清**：① 叫心理评估/基线；② 叫跟踪/快照；③ 叫职场画像——勿把②标成「心理评估」。  
3. **与疏导一致**：三块对应疏导三源（§0.8）；从本页「去聊聊」可带上已有源。  
4. **顶栏快捷**（可选）：「去做心理评估」「再测此刻」「职场画像」三个入口，与三块对应。  

**反例**：只有「你留下来的评估」混排时间线，看不出基线/快照/画像。  
**正例**：一屏或短滚即可辨认三块标题与各自状态。

## 5. 能力设计

> 结构：**5.4 职场心理教练**与 **5.5 心理健康跟踪**是产品主身份与状态层；**5.1–5.3 三关**是教练场景下可调用的过关训练工具。

### 5.1 人事关：简历评分与改写（过关工具）

**输入**

- 简历全文（结构化优先：工作经历 / 项目 / 优势）  
- 目标 JD  
- 可选：求职意向主线（如「车联网合规产品」）

**输出**

| 维度 | 说明 |
|------|------|
| 匹配度 | 与 JD 关键词 / 职责的覆盖 |
| 主线清晰度 | 是否像一条可讲的职业故事 |
| 可信度 | 量化、客户/场景、职责边界是否清楚 |
| 风险项 | 时间断层、过短经历、术语硬伤、夸大风险 |
| 改写建议 | 按段落：保留 / 压缩 / 重写 / 补量化 |

**评分原则（产品约束）**

- 必须给出**扣分理由**，禁止只给分数  
- 建议按「人事会怎么刷」写，不用业务黑话堆砌  
- 改写默认**不编造经历**；缺信息标「待用户补充」

### 5.2 业务关：面试模拟（过关工具）

**输入**

- 简历 + JD（继承任务）  
- 可选：用户指定要练的案例（如 SRM、法规库解耦）

**流程**

1. 1 分钟自我介绍（含匹配点）  
2. 深挖 1–2 个项目（追问链）  
3. 情景题 / 压力题（计划拆解、冲突、短板）  
4. 反问环节提示（用户问面试官什么）

**诊断维度（针对「表层化」）**

| 维度 | 表层表现 | 合格表现 |
|------|----------|----------|
| STAR 完整度 | 只有背景和职责 | Action/Result 具体 |
| 决策与取舍 | 只说「后来做成了」 | 选项、标准、谁拍板 |
| 个人贡献 | 「我们」过多 | 清楚「我做了什么」 |
| 复盘 | 无 | 若重来会怎么做 |
| JD 迁移 | 硬套旧经验 | 说清可迁移方法与边界 |

**输出**

- 本轮深度分 + 最弱 1–2 点  
- 针对最弱题的「补强口述稿」（60–90 秒）  
- 可收藏为案例库条目

### 5.3 谈薪关：与 HR 沟通辅助（过关工具）

**输入**

- 当前：月薪结构、年终、奖金、公积金基数、补贴  
- Offer：基本/岗位/绩效、年终口径、试用期、调薪、其他  
- 用户底线与目标年包  

**输出**

- 双方**真实年包区间**（保守 / 目标 / 乐观）  
- 结构风险点（基本过低、年终不保、流水压价等）  
- 优先谈的 3 个点 + 可放弃的点  
- 话术：说明「应收结构 vs 流水」、要证据时怎么递  

**原则**

- 不算「保证你谈到 X」；给**决策信息 + 表达模板**  
- 明确标注：年终/绩效系数未书面确认时，按区间展示，不按满额单点展示  

### 5.4 职场心理教练（产品主身份）

**定位**：主故事线步骤 5 的核心——AI 心理疏导；并可导向私人心理辅导预约。

**关联细则**

| 主题 | 文档 |
|------|------|
| 会话气质与文案 | [`体验与文案_温暖感样板.md`](./体验与文案_温暖感样板.md) |
| 疏导三源合读 | §0.8；画像 + **心理评估/基线** + 快照 |

**输入（疏导开场 · 有则必读）**

| 源 | 规则 |
|----|------|
| 职场画像 | 若有 → 注入最新人设/标签/五维摘要与配合提示 |
| 心理评估（基线） | 若有 → 注入**最新**基线 + AI 分析摘要（评估主体） |
| 快照 | 若有 → 注入**最新**（或本会话关联）快照（跟踪态） |
| 诉求 / 场景 | 用户已选或待确认的诉求（求职 / 晋升 / 沟通等） |
| 其他 | 可选：关联求职任务、晋升节点、冲突对象角色 |

三者皆无 → 通用开场，可软提示「补画像/心理评估后更懂你」。**禁止**已有数据却不注入。

**流程（建议固定骨架）**

1. **模式**：轻试玩（可不做基线、快照可跳过）/ 正式疏导（建议快照；无基线时快照后引导续做）  
2. **澄清**：事实 vs 自我评判  
3. **命名情绪与需求**  
4. **重构选项**与 24h 可执行动作 / 话术  
5. **分支**：找工作 → 三关；晋升/沟通 → 对应服务  
6. **预约**：用户可发起私人心理辅导预约（深度个性化时可引导补做初次评估，仍可稍后）  
7. **安全检查**：危机信号 → 转介，不继续常规疏导  

**私人心理辅导预约（步骤 6 增强）**

| 项 | MVP 建议 |
|----|----------|
| 能力 | 用户提交预约意向（时段偏好、诉求摘要、联系方式约定） |
| 履约 | 人工确认或对接外部咨询师；产品内展示预约状态 |
| 边界 | AI 疏导 ≠ 临床治疗；预约是专业支持通道，不承诺诊疗效果 |
| 与评测 | 预约前**推荐**完成心理评估（基线）以便了解背景，但**不设死门禁**（可边约边补） |

### 5.5 心理健康跟踪（状态层 = 快照的回看面）

**定位**：主故事线步骤 8。**跟踪记录单元 = 快照**（不是心理评估本体；**心理评估 = 基线**，见 §0.7）。与「是否已做基线」解耦。

**实现必读**

- 命名与入口：§0.7  
- 快照题面：[`三分钟自评表.md`](./三分钟自评表.md)  
- 心理评估（基线）：[`基线问卷.md`](./基线问卷.md)  

**问卷策略**

| 时机 | 用哪一层 | 是否拦截 |
|------|----------|----------|
| 工作台「心理评估」 | **基线** | **不拦截进门**；可稍后再说 |
| 认真聊主行动区 | **快照**；无基线则引导去做心理评估 | 正式会话建议填快照；轻试玩可跳过；当日已有可沿用 |
| 预约私人辅导等节点 | 推荐做/更新**心理评估（基线）** | 软提示，不设死门禁 |
| 「再测此刻」/ 页底跟踪 | **快照** | 自愿；禁止标成心理评估本体 |
| 可选重测基线 | 同一基线卷，随时可再提交 | 自愿；≥90 天软提示；禁止只能一次 |

**输出**

- 近 7 / 30 日压力与情绪趋势（**仅**由快照汇总）  
- 「高压日」与诉求/事件对照  
- 「我的评估」页固定三块：①基线结果 ②跟踪快照 ③职场画像（§4.1）  

**原则**

- 默认私密、仅本人可见  
- AI 分析只用描述性语言，**禁止诊断病名**  
- 连续高压或危机相关作答 → 提示专业资源 / 引导预约，而非加强产品内依赖  
- **禁止**用基线卡住「先看看产品有什么」的用户  
- **禁止**心理评估（基线）没有产品内可见入口  
- **禁止**把快照对外标成「心理评估」本体，导致基线入口弱化或失踪  
- **禁止**另做与快照并行的日常打卡问卷  
- **禁止**基线「终身只能一次」或做过一次后藏掉更新入口  

### 5.6 职场大五画像（趣味建档）

**定位**：参考 OCEAN 的约 15 题速测；产出五维数据、带刺人设与代价向标签；提高完测趣味并为疏导提供风格上下文。

**实现必读**：[`职场大五画像问卷.md`](./职场大五画像问卷.md)（15 题原文、反向题、计分、人设一段合写、标签、教练摘要边界）。  
**路径**：可选 → 结果页「带着画像去聊聊」；可注入 `CoachSession` 开场上下文。  
**不做**：进门强制；官方量表版权原题；病理化/羞辱性标签；录用筛选承诺；纯表扬鸡汤人设；结果页「双刃/硬伤」分栏复读。

## 7. 关键用户流程

### 主流程：首访到可持续使用（§0.4 / §0.5）

1. **链接登录**进入应用 → **落地工作台**（可先体验，不强制基线）  
2. （可选）**职场大五画像** 15 题 → 五维 + 人设 + 标签 → 可去聊聊  
3. **心理评估**（§0.7）：工作台进入**基线问卷** → AI 分析；认真聊另走快照门禁并可引导去做评估  
4. **确认诉求**：推荐结合职场画像（若有）+ 基线·最新（若有）+ 快照·最新（若有）；确认后按 §0.5-B **直达**  
5. 「我的评估」：基线结果 + 跟踪快照 + 职场画像（三块，§4.1）  
6. 工作台疏导：轻松聊直达 / 认真聊经快照（无基线则引导去做心理评估）  
7. 找工作练习室；跟踪复用快照  


### 子流程 A：求职三关

1. 新建任务 → 上传简历 + 粘贴 JD  
2. 人事关 → 看分与红灯 → 改写  
3. 业务关 → 模拟与诊断  
4. 谈薪关 → 结构对照与话术  

### 子流程 B：晋升 / 沟通服务（含诉求确认直达）

1. 在诉求页点选晋升/沟通（或工作台点场景）  
2. 若当前为认真聊且缺快照 → 先快照（带回跳）；无基线时结果页提供「继续完善基线」  
3. **直接进入**对应场景教练会话（不经 home 中转）  
4. （增强）述职/沟通专项训练可从会话侧链出  

### 子流程 C：私人辅导预约

1. 从疏导页或工作台发起预约  
2. 填写时段与备注 → 待确认  
3. 确认后履约；回访可再引导问卷跟踪

## 8. 技术选型

结合已有栈（Vue3 + Go + SQLite）与已拍板约束：

| 层 | 选型 | 理由 |
|----|------|------|
| 前端 | Vue 3 + Vite | 熟悉；工作台 SPA |
| 后端 | Go | 熟悉；上传与 API 清晰 |
| 存储 | JSON 文件（`data/tasks.json`） | M1 零 CGO、依赖少、易备份；后续可换 SQLite |
| 部署 | **可公网/局域网访问的 Web 服务**（非纯本机桌面工具） | 方便真实投递场景随时用；可用单机 Docker / 一台云主机 |
| AI | OpenAI 兼容协议，**服务端对接自有中转站** | Key 与 Base URL 仅服务端配置，不暴露给终端用户 |
| 文档解析 | **Markdown / 纯文本 / docx / PDF** 均需支持 | MVP 输入门槛对齐真实投递材料 |

### 模块划分

```
apps/web          # Vue3 工作台
apps/api          # Go HTTP API
  /auth/link              # 链接登录
  /assessments            # 基线问卷与 AI 分析、我的评估
  /needs                  # 诉求确认
  /coach/sessions         # AI 心理疏导
  /counseling/bookings    # 私人心理辅导预约
  /wellbeing/questionnaires  # 跟踪问卷（含三分钟自评）
  /tasks /hr /interview /salary   # 求职三关
internal/prompts  # 【统一维护】各角色 system prompt（常量导出）
internal/llm      # 中转站 HTTP client（不含业务提示词）
internal/resume   # 简历解析
```

现状（待收敛）：提示词仍散落在 `coach` / `assessment` / `hr` / `interview` / `salary` 等包内的 `systemPrompt` 常量；方案要求收到 `internal/prompts`。

### AI 调用原则

- **评测分析** / **教练疏导** / 人事 / 业务 / 谈薪 / 简历改写使用不同 prompt 与 schema  
- 评测分析与疏导均须：职场向、禁止临床诊断、危机识别与转介  
- 疏导上下文注入：最近问卷、AI 评估摘要、已确认诉求  
- 中转站配置仅服务端；心理健康数据单独强调隐私说明  

### 提示词维护（已拍板）

| 项 | 决策 |
|----|------|
| 存放位置 | 统一在 `apps/api/internal/prompts/`（可按角色拆文件，如 `coach.go`、`hr.go`） |
| 形态 | Go 导出常量（如 `prompts.CoachSystem`）；业务包只引用，不内嵌长文案 |
| 职责边界 | `internal/llm` 只负责请求模型；**不含**角色提示词 |
| 覆盖范围 | 教练疏导、初次评测分析、人事分析、简历改写、业务面模拟、谈薪分析（及后续新增角色） |
| 暂不做 | 运营后台在线改词、独立 md/yaml 热加载（需要时再立项） |

原则：改文案只改 prompts 包；改流程/解析仍在各业务包。与「三角色/多角色隔离」一致——统一目录，分文件或分常量，禁止揉成一个万能 prompt。

### 简历解析原则

| 格式 | MVP 要求 |
|------|----------|
| Markdown / 纯文本 | 直接入库与结构化 |
| docx | 抽正文与基本标题层级，再结构化 |
| PDF | 抽文本（优先可选中文本型 PDF；扫描件 OCR 标为降级/二期增强） |

解析失败时明确报错并允许用户改贴纯文本，不静默空跑。

## 9. MVP 范围与非目标

### MVP 做（主故事线必须可演示）

按 §0.4 主路径验收，并验收**「可先体验、后评测」**。

- **链接登录**后默认进入工作台，**不强制**基线评估  
- 功能可先体验：疏导轻试、求职三关、晋升/沟通入口、预约说明  
- **职场大五画像**（约 15 题，可选）：五维数据表 + 人设 + 附加标签  
- **心理评估（基线）**：工作台/我的评估有入口；可多次更新 → AI 报告；快照另属跟踪  
- **诉求确认**（画像 + 心理评估包若有；皆无也可自选；确认后直达）  
- **我的评估**：固定三块——基线结果、跟踪快照、职场画像（§4.1）  
- **AI 心理疏导** + **私人心理辅导预约**入口与状态  
- **求职子流程**与**晋升/沟通**可在未完成基线时试用  
- 正式疏导/跟踪节点：快照写入曲线  
- 中转站 + SQLite；简历 md/txt/docx/pdf  

### MVP 不做

- 自动投递 / 爬岗位 / 替代 Boss 直聘  
- 完整多租户 SaaS 计费与开放自助注册（链接/白名单受控即可）  
- 终端用户自填模型 Key  
- 临床诊断、药物建议、危机陪护  
- 企业管理者查看员工心理数据的组织端监控  
- 扫描件 PDF 高精 OCR；英文面试专线  

说明：原「不做真人咨询师撮合」调整为——**支持私人心理辅导预约通道**（人工确认/外部对接），仍不在产品内开展诊疗。
