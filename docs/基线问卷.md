# 基线问卷（= 心理评估主体）

> **产品名**：对外「**心理评估**」主要指本卷（基线）+ AI 报告；快照是跟踪，不叫心理评估本体（见产品方案 §0.7）。  
> **文档原名**：初次心理评估问卷（已更名删除，仅保留本文）。  
> **一体定位**：与 [`三分钟自评表.md`](./三分钟自评表.md)（快照/跟踪）衔接，但**评估主体是本卷**。  
> **可多次填写**：用户可随时「更新心理评估 / 更新基线」，历史多份保留，业务取**最新一次**。  
> **非进门必做**，但**必须有可见入口**（工作台「心理评估」、我的评估）；有基线后入口改为「更新」，不得消失。  
> 用途：补全场景/压力源/期望/安全筛查，用于 AI 分析与推荐。  
> 性质：**职场向自我评估**，不是临床心理测评，不做诊断、不开药、不替代持证咨询。  
> **主入口**：[`产品方案_v1.md`](./产品方案_v1.md) §0.7 · §0.8 · §0.4 步骤 3–4 · §5.5  
> 姊妹：[`三分钟自评表.md`](./三分钟自评表.md)（快照）· [`职场大五画像问卷.md`](./职场大五画像问卷.md) · [`体验与文案_温暖感样板.md`](./体验与文案_温暖感样板.md)  
> **疏导用法**：有则必注入，并与**最新快照、职场画像（若有）合读**（§0.8）。  
> 版本：v1.6 · 2026-08-11

## 0. 为什么还有「长」这一层？

| 问题 | 答案 |
|------|------|
| 为什么不和三分钟合成一份永远通吃的卷？ | 每次认真聊都填 5–8 分钟会劝退；快照只解决「此刻与想带走什么」。 |
| 为什么不能只有三分钟？ | 缺少主场景、压力源、期望、安全筛查 → AI 报告与个性化偏薄。 |
| 用户怎么理解？ | 始终是「心理评估」：先快照，无基线时同流续做本卷；有基线后可「更新基线」，不是两套无关入口。 |
| 是不是只能做一次？ | **否。** 可多次提交；时间线保留历史，推荐/教练注入取**最新基线**。≥90 天只是软提醒，不是锁死。 |

## 1. 使用说明

### 1.1 何时填写

- **首次**：工作台 / 我的评估「完善基线评估」；或快照结果「继续完善基线」  
- **再次（允许随时）**：同一入口改为「更新基线」/「把底再补一补」——**不设次数上限、不设必须满 90 天才能提交**  
- **可引导**：预约私人辅导、打开「我的评估」；距上次 ≥90 天或重大状态变化（如离职）可**软提示**更新，仍可「稍后再说」  
- **不要**：登录后唯一强制全屏门禁；产品里只有三分钟入口、基线无处可点；**做过一次后藏掉更新入口**  
- 日常跟踪用快照层；基线是「阶段性建档/更新」，不是每日打卡  

### 1.2 填写体验约束

| 项 | 建议 |
|----|------|
| 时长 | 5–8 分钟 |
| 题量 | 约 20–25 题（含 1 道开放题） |
| 跳题 | 按「当前主场景」分支，避免无关题刷屏 |
| 结果页 | 给「状态摘要 + 建议教练场景 + 是否建议专业求助」，**禁止**输出诊断病名 |
| 与快照 | 近几日已有快照时，结果可引用快照摘要，减轻「填两遍」感 |

### 1.3 隐私与知情

开填前固定展示：

1. 答案仅本人可见（首发无组织端监控）  
2. 用于教练个性化与趋势对照，不作录用/晋升评判依据  
3. 若出现危机相关选项，将展示专业求助资源，产品不提供危机陪护  

用户需勾选「我已知晓」后方可开始。  
若从快照「继续完善基线」进入，知情可缩短为确认句，避免重复长文。

### A. 知情与背景

**A0.** 我已阅读并知晓：本问卷为职场自我评估，非临床诊断。  
- [ ] 已知晓，开始填写  

**A1.** 你当前最想优先处理的场景是？（单选，决定分支）

- 其他（短填）

### E. 安全筛查（必答，极简）

> 说明：以下用于判断是否需要展示专业求助资源，**不是**诊断。

**E1.** 近 2 周，是否有过「活着没有意思」或伤害自己的想法？  
- 完全没有  
- 偶尔有过一闪而过的念头，但能自己拉开  
- 较频繁，或已有具体计划 / 行动（任一即触发危机资源）  

**E2.** 若选「较频繁…」：展示危机资源卡，并建议暂停深度教练、优先寻求线下专业/紧急帮助。产品内仅保留「我已知晓资源」确认，不继续高压追问细节。

## 4. 计分与结果呈现（产品逻辑）

### 4.1 基线指标（内部用，可对用户展示「摘要」而非原始算法名）

| 指标 | 计算示意 | 用途 |
|------|----------|------|
| 压力基线 | B1 | 跟踪对照起点 |
| 情绪负荷 | mean(B2, B3, B4) | 教练开场语气与节奏 |
| 精力—睡眠 | B5 反向关注低分；B6 高分需提示休息 | 行动建议可行性 |
| 场景痛点强度 | C2 + 对应分支题 | 推荐场景与是否建议先教练再三关 |
| 支持充足度 | D2 | 是否强调外部支持资源 |
| 危机标记 | E1 | 覆盖层展示求助资源 |

### 4.2 结果页结构（对用户）

1. **状态一句话**：如「近两周压力偏高，求职自我否定较明显」——只用描述性语言  
2. **建议主场景**：求职 / 晋升 / 沟通（来自 A1 + C 区）  
3. **建议下一步**：先开一次教练会话 / 先打卡 3 天 / 需要时进入某关训练  
4. **边界提示**：再次说明非诊疗；若危机标记为真，置顶专业资源  

### 4.3 禁止输出

- 任何精神疾病诊断名或「你有某某症」  
- 「保证你焦虑消失 / 一定升职拿到 offer」类承诺  
- 把问卷分数直接当作录用或能力评价

## 6. 与快照层（三分钟自评）的关系

| | [基线问卷](./基线问卷.md)（=心理评估） | 快照（本文） |
|--|-------------|----------------------------------------|
| 产品名 | **心理评估** | 跟踪 / 再测此刻 |
| 频率 | **可多次**；随时更新；≥90 天仅软提醒 | 认真聊 / 节点 / 跟踪，可反复 |
| 深度 | 场景、压力源、期望、安全筛查 | 感觉、时长、影响、0–10、想带走什么 |
| 作用 | AI 报告、个性化推荐（取**最新**一份） | 当次开场对齐、写入曲线 |
| 入口 | 工作台「心理评估」/ 我的评估（**必有**） | 认真聊主行动区；「再测此刻」 |
**重测规则（拍板）**

| 规则 | 说明 |
|------|------|
| 硬限制 | **无**。后端允许多条；前端不得因「已有基线」禁止进入问卷页或禁止提交 |
| 取用 | 诉求推荐、教练注入、我的评估摘要均取 **completed_at 最新** 的基线 |
| 历史 | 旧基线留在时间线可回看，不覆盖删除（除非产品另做用户删除） |
| 软提醒 | 距上次 ≥90 天，或用户主动、或重大节点变化 → 提示「要不要更新一下底」；可稍后再说 |

## 7. 文案示例（结果页）

**常规**

> 感谢你的填写。根据你的回答，近两周压力与自我否定偏高，当前更适合先从「求职场景」的教练对话开始：把挂面后的自我攻击和可改进点拆开。  
> 之后可用「再测此刻」（快照）看见状态变化；需要改简历或练面试时，再进入过关训练。  
> 本评估用于自我觉察与教练个性化，不是心理诊断。

**危机标记**

> 你标出了需要被认真对待的痛苦信号。建议优先寻求专业或紧急支持（展示本地/通用求助资源列表）。  
> 产品内的职场教练不适合处理危机时刻；你确认已知晓资源后，仍可稍后使用快照与非危机向的教练功能。
