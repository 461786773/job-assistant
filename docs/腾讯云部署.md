# 求职助手 · 腾讯云部署说明

## 包内容

```
bin/job-assistant     # Linux amd64 可执行文件（已静态编译）
web/                  # 前端静态资源（由 Go 托管）
data/                 # 运行时数据与日志（启动后生成）
.env.example          # 环境变量模板
start.sh / stop.sh / restart.sh
job-assistant.service # systemd 可选
```

## 1. 上传

把 `job-assistant-linux-amd64-*.tar.gz` 上传到腾讯云 CVM，例如：

```bash
scp job-assistant-linux-amd64-*.tar.gz root@你的公网IP:/opt/
```

## 2. 解压

```bash
cd /opt
tar -xzf job-assistant-linux-amd64-*.tar.gz
cd job-assistant-linux-amd64-*
# 可选：软链固定目录名
# ln -sfn "$(pwd)" /opt/job-assistant
```

## 3. 配置环境变量

```bash
cp .env.example .env
vi .env
```

推荐生产配置：

```bash
JA_ADDR=:8080
JA_ROOT=.
JA_DATA_DIR=./data
JA_UPLOAD_DIR=./data/uploads
JA_WEB_DIR=./web

JA_LLM_BASE_URL=https://api.deepseek.com
JA_LLM_API_KEY=sk-你的密钥
JA_LLM_MODEL=deepseek-v4-pro
```

说明：`JA_LLM_BASE_URL` 到 `/v1` 或官方根域名为止（本服务会拼接 `/chat/completions`）。DeepSeek 官方可用 `https://api.deepseek.com`。

## 4. 启动 / 停止

```bash
chmod +x start.sh stop.sh restart.sh bin/job-assistant
./start.sh
./stop.sh
./restart.sh
```

验证：

```bash
curl http://127.0.0.1:8080/api/health
# 期望: {"ok":true,"llm":true,...}
```

浏览器访问：`http://服务器公网IP:8080`

## 5. 安全组 / 防火墙

腾讯云控制台 → 云服务器 → 安全组，放行入站 **TCP 8080**（或你改的端口）。

若用 Nginx 反代 80/443，可只放行 80/443，后端仅本机访问 8080。

### Nginx 反代示例

```nginx
server {
  listen 80;
  server_name your.domain.com;

  client_max_body_size 25m;

  location / {
    proxy_pass http://127.0.0.1:8080;
    proxy_set_header Host $host;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    # 不要对 HTML 做 proxy_cache；后端已对 index.html 设 no-store，
    # 对 /assets/*（Vite hash）设长期 immutable。
  }
}
```

### 发版后用户不用强制刷新

前端是 Vite 构建：`/assets/index-xxxx.js` 文件名带内容 hash。  
后端对 **`index.html` 禁止缓存**，对 **`/assets/*` 长期缓存**。  
只要线上完成 `git pull` → `npm run build` → `go build` → 重启进程，用户下次普通打开/刷新就会拿到新 `index.html`，从而自动指向新 JS，**不必 Cmd+Shift+R**。

## 6. 使用 systemd（可选，推荐）

```bash
# 假设解压到 /opt/job-assistant
sudo cp job-assistant.service /etc/systemd/system/
sudo sed -i 's|/opt/job-assistant|/opt/实际目录|g' /etc/systemd/system/job-assistant.service
# EnvironmentFile 与 WorkingDirectory 需指向真实路径
sudo systemctl daemon-reload
sudo systemctl enable --now job-assistant
sudo systemctl status job-assistant
```

用 systemd 时不必再跑 `./start.sh`。

## 7. 日志与数据

- 应用日志：`data/app.log`
- 任务数据：`data/tasks.db`（SQLite；若有旧版 `tasks.json` 会自动导入一次）
- 上传简历：`data/uploads/`

备份时打包整个 `data/` 目录即可。

## 8. 常见问题

| 现象 | 处理 |
|------|------|
| `llm:false` | 检查 `.env` 的 `JA_LLM_*` 是否生效，改完后 `./restart.sh` |
| 外网打不开 | 安全组是否放行端口；本机 `curl 127.0.0.1:8080/api/health` 是否正常 |
| 402 / 余额不足 | 模型服务商账户充值 |
| ARM 机型 | 本包默认 amd64；需在打包机用 `GOARCH=arm64 ./scripts/package-release.sh` 重打 |

```bash
chmod +x scripts/package-release.sh
./scripts/package-release.sh
```

产物在 `dist-release/job-assistant-linux-amd64-*.tar.gz`。
